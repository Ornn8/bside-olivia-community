# 每日衣橱

世界页提供独立衣橱入口。用户只能指定风格，不能指定某套衣服或上传生成提示。云端保存偏好，林离在首次需要人物照片时选择当天搭配；同日同一偏好版本复用一套，修改风格立即影响随后接受的新任务。

首批风格为原版日常、森女系、叛逆学院、暗黑古着、工装酷感、领带短裤。陈列提供18套服装参考，森女系14套，其余四种各1套。发型保持林离当前长度，服装人台不作为人物身份参考。

客户端 GET/POST `/toy/world/wardrobe` 代理云端 GET/POST `/v1/wardrobe`。写入只允许 `request_id` 和 `style_id`；保存失败保留已确认的偏好。客户端仅在成功回执后更新界面。参考图通过本机 `/toy/wardrobe/images/<look_id>` 代理读取，浏览器不持有账号密钥。

图片任务的提交、读取、恢复和取消携带 `X-Olivia-Wardrobe-Protocol: daily-v1`。云端支持时返回只读 `media_plan.daily_outfit`，包含日期、时区、偏好版本、风格、套装、目录版本和参考图校验值。客户端验证此对象；旧四字段规划仍兼容。套装信息不能作为用户输入提交，旧任务不根据当前偏好重新选装。

日期按云端世界时间 Asia/Shanghai 划分。排队跨日、改风格、重新连接和重试都保留原任务冻结的搭配。重复保存同一风格不重选；同日A→B→A产生新的偏好版本。

照片第三视角仅在确认外出时使用朋友帮拍的摄影编排，外出的咖啡店、书店等室内场所也可使用。在家、地点不明或仅准备外出时不启用，不能为摄影效果改变世界地点。

视频后台补送与每日视频换装是独立能力。本次客户端包含原视频订单恢复和后台补送，视频换装仍等待生产渲染接口与真实服装一致性验收，不能以本地合同测试宣称换装上线。
