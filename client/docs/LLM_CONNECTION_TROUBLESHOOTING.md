# 大模型连接失败排查

先按界面显示的错误处理；回信形式检测失败时，信件尚未寄出，草稿保留。不要连续重复提交，也不要先删除信件、记忆或重装模型。

| 提示 | 处理方式 |
|---|---|
| `LLM_TLS_FAILED`：证书校验失败 | 同步 Windows 日期、时间和时区；使用最新版客户端。客户端保留系统信任并补充附带的公共根证书。若使用代理或 HTTPS 检查软件，检查其证书部署是否完整，或用可信网络对比。服务器证书过期、域名不匹配或证书链不完整，需要服务提供方修复。不要关闭证书校验。 |
| `LLM_DNS_FAILED`：地址解析失败 | 核对服务地址，检查网络及 DNS 设置。地址正确且多个网络都失败时，联系服务提供方。 |
| `LLM_CONNECTION_FAILED`：连接失败或中断 | 检查网络、代理和防火墙是否允许应用访问服务地址；连接恢复后再试。不要整体关闭安全软件。 |
| `LLM_AUTH_FAILED`：认证失败 | 在大模型设置中检查所选服务、API Key 和访问权限。不要把完整 key 发到聊天或截图中。 |
| `LLM_QUOTA_EXHAUSTED`：额度不足 | 检查对应服务账户余额或额度；不能靠重新导入本地组件解决。 |
| `LLM_RATE_LIMITED`：请求过于频繁 | 等待后再试，减少同时请求，不要反复点击发送。 |
| `LLM_TIMEOUT`：响应超时 | 检查网络并等待服务恢复；若持续出现，导出诊断包以区分请求阶段和响应阶段。 |
| `LLM_SERVICE_UNAVAILABLE`：服务端暂不可用 | 稍后重试，持续出现时交由服务提供方排查。无需重装本地组件。 |
| `REPLY_ROUTE_INVALID_RESULT`：返回格式无法识别 | 保存诊断包，检查所选模型与服务接口的结构化输出兼容性。 |

上述类别表示失败发生的环节，不足以单独证明具体根因。持续失败时，在一次失败后尽快导出诊断包，并提供发生时间和客户端版本；不要提供完整 API Key。
