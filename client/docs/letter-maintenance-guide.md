# 信件对比与整理

从 2.0.12 开始，月离设置页里多了一个叫「信件对比与整理」的地方。位置在「信件与记忆 → 导入与导出信件」里面，
平时是收起来的，点一下标题才展开。

它管的是这么一类麻烦：你从灵离那边搬过来的老信，时间显示得乱七八糟；信箱里同一封信出现了两遍；
或者堆着几封一直显示失败、又删不掉的。

处理这些东西的时候，它不动信的正文，不动林离的长期记忆，也不调用大模型（所以不花钱），
连月离都不用退。而且做过的整理随时能撤销——收起来的信不是删掉，还在原地，随时可以放回来。

## 先看清楚它长什么样

展开之后，界面上有一句话说明它还顺便帮你对比备份：

> 先检查，再选择要整理的信件。可以对比 .soul 或 JSON 备份、修复时间和顺序、收起重复信与失败信。
> 整理只影响信箱显示，不改原文或长期记忆，也不调用模型；可在这里恢复。

底下是三个按钮。

「检查当前信箱」不用选任何文件，点一下它就去读现在的信箱，把有问题的信列出来。

「选择备份对比 / 修复时间」会让你挑一份文件——灵离的「.soul」，或者你以前从月离导出的
「Olivia-letters-xxxx-xx-xx.json」。挑完它会把备份和信箱里的信一条一条对上。

「应用所选」是最后一步，把你挑好的处理方式真正用上。选之前它会再问你一次。

按钮下面还有上一页 / 下一页，一页放三十条。

## 时间不对，怎么修

点「选择备份对比 / 修复时间」，选中那份「.soul」。过一会儿状态栏会告诉你有多少东西：

> 对比文件：xxx.soul。共 N 项；完全重复 x，近似重复 y，可修复时间 z，失败信 q，可恢复 l。

然后往下翻，找标着「可修复时间与顺序」的条目。每条都是左右两栏并排，左边是信箱里那封，
右边是备份里那封，各自的时间写在上面（按北京时间显示）。你要看的就是这两封是不是同一封信、
备份那边的时间对不对。

每条的下面有个「处理方式」下拉，默认是「保持原样」。想修就选「按备份修复时间和顺序」，
它会照备份里那封的日期和位置来改。改好一页，点「应用所选」，确认，再翻下一页。

注：这里有个地方容易踩：翻页会把这一页的选择清空。界面上写着「翻页会清空本页选择，请先应用」。
所以节奏是一页一页来——挑、应用、再翻。别一口气翻到底再想回头选。

另外，一次只对比一个备份文件。中途换文件的话，重新检查一遍。

如果某条标的是「正文有差异 · 仅对比，不自动覆盖或修复时间」，那说明备份里那封和信箱里
那封正文不一样。这种它只摆给你看，不会替你改。一般这种情况该走下面说的「收起重复」，
而不是修时间。

## 信箱里有重复的信

这个不用选文件，直接点「检查当前信箱」就行。

它会把问题分几类告诉你，每一类的处理方式不太一样：

- 「完全重复」——去信回信一个字都不差。选「保留右侧，收起左侧」，留一份，其余收起来。
- 「近似重复 · 请核对两侧正文」——很像但不完全一样。这种得你自己对着两边看，决定留哪版。
- 「可修复时间与顺序」——备份里有同内容的信而且带日期，照它改就行（要选文件才看得到这类）。
- 「失败或已取消的信件」——那些一直卡着的信，可以直接从信箱收起来。
- 「旧工具导入信」——明确是外部工具导进来的，也能收。
- 「已整理 · 可恢复」——之前整理过的。选「恢复整理前的显示和时间」就还原回去。
- 「内容一致」、「仅信箱中存在」——没问题，列出来只是让你心里有数，不用动。
- 「仅备份中存在」——备份里有、信箱里没有。这个要回到上面的「选择文件导入」把它导进来。
- 「备份存在多个日期 · 暂不修复」——备份里同样的内容配了好几个日期，它自己拿不准，就不改了。
  这是故意保守，免得改错，不用管它。

「收起」不是「删除」：收起来的信正文还在，只是不在信箱里显示了；下次进来它会变成
「已整理 · 可恢复」，选一下就回来。所以这一步可以放心试，不会弄丢东西。

## 它到底碰了什么？

这一点可以放心：

- 信件的正文，一个字都不动。
- 林离的长期记忆不动。
- 不调用模型，不产生任何费用。
- 不用退出月离。
- 记忆数据库也不写。整理的结果只记在信箱自己的那份状态里。

还有个细节说一下：月离导出信件备份、以及导入时判断重复，看的都是「整理之前」的样子。
所以「先按备份把时间修好 → 再导出一份备份 → 换台电脑导进去」这条路是通的，不会因为改过时间就重复。

## 它和「导入」是两件事

容易混的是这个：「时间好不好看」，和「林离记不记得住」，不是一回事。

「信件对比与整理」只管信箱里显示的样子。你把它修得再整齐，也不会让林离多记住一个字。
真要她记住，得走「选择文件导入」把信写进记忆档案，然后别关月离，让它挂着——后台会把
这些信慢慢灌进检索里（每五秒二十封左右），同时每五封调一次模型评估关系，这个过程要花一点额度，
设置页能看到进度。

所以顺序是：先导入，挂着等它跑完，再回来整理显示。

## ！！！重点注：有一条别踩

别拿「Olivia-letters-xxxx-xx-xx.json」走「选择文件导入」。

这么干会重复。原因是月离判断「这封信有没有来过」的时候，把时间的写法也算进去了：
从「.soul」进来的是北京时间、写成 +08:00，而数字时间戳会被换算成 +00:00——明明是同一个时刻，
两个字符串，它就当成两封不同的信。而「.soul」那条路多一道「按正文比对」的保险，不看时间，所以不中招。

需要按备份修时间，就在「信件对比与整理」里做；需要按备份补信，优先用「.soul」。
这两条都行，就是别拿那个 json 反复导。

## 提示看不懂的时候

界面上可能出现这么几句话，对应的意思是：

- 「备份无法读取。请选择完整的 .soul 或 JSON 文件（文字清单最大 16 MB）。」——文件选错了，或者太大。
- 「信箱已变化，请重新检查后选择。」——你检查完到点应用之间，信箱被别的地方改动了。重新检查一遍就行。
- 「正在导入或整理记忆，请稍后重新检查。」——有别的写入在跑，等一下再来。
- 「无法保存信箱整理结果，请检查磁盘后重试。」——八成是磁盘满了。
- 「所选操作有冲突…」——同一封信被选了互相打架的两项，重新检查一次再挑。
- 「信件较多，本次仅完成部分近似对比；完全重复检查已覆盖全部。」——近似对比有次数上限，
  但完全重复是全量比对的，不影响你找重复信。

如果「检查当前信箱」说没什么要整理的，那就是真的干净，不用管。

## 什么时候该用别的工具

月离还附带一个小工具（在「install\versions\local_backend\」下面那个版本目录里的「tools\olivia_memory\」，
双击「运行.bat」打开）。日常修信箱显示已经用不上它了，但有几件事只有它能做（内附详细图文使用说明）：

- 体检——看看记忆档案里到底有多少封、检索索引里有多少条。
- 回退月离版本（万一补丁把游戏搞到打不开）。
- 把「记忆档案里」那封信的日期也改对。因为「信件对比与整理」不写数据库，
  只改信箱显示；你要是希望林离回忆旧信时带的时间也准，就得用它。
