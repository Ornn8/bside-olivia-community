# 图片按需下载

新安装客户端默认自带 108 个线稿表情包，信件与 QQ/微信都可离线使用；已有客户端应用补丁时保留原生资源中的这套线稿。程序补丁保留图片目录与校验值，不重复携带 PNG、JPEG、GIF、WebP 等图片文件。衣橱保留全部 47 套参考，表情包保留全部 272 个条目；启动和读取目录不下载整批图片。

首次显示衣橱参考或支付二维码，以及首次向 QQ 发送选中的其他表情包时，客户端获取下载票据，从 R2 下载这一张图片。图片保存到安装数据目录 `data/image-assets/<类别>/<sha256>/<文件名>`，独立于补丁版本目录。缓存校验通过后直接本地读取，不依赖网络；更新补丁和重新启动保留已下载的图片。图片内容变化时采用新的校验值，下载新版文件。默认线稿直接读取本机客户端资源，聊天发送时可从原生资源提取到同一持久目录。

客户端仅接受目录中的编号与准确的 R2 对象路径，不持有 R2 密钥。下载限制大小并核对 SHA256，使用临时文件和原子替换；过期票据重新获取。失败不落盘为可用图片，也不影响已经完成的文字回信。图片下载本身不走生成或计费链路。关系解锁、QQ 专属表情包范围和每日穿搭选择不变。

部署顺序：先将对应的不可变对象上传并验证到 R2，配置云端 `OLIVIA_IMAGE_ASSETS_MANIFEST`，接入 GET `/v1/components/images/<类别>/<编号>`（短效签名票据），验证公网票据与文件下载，再允许发布客户端补丁。客户端的 `runtime/image_assets.json` 与服务器使用同一份已验证目录。Nginx 只将准确的图片票据路径转发给现有模型服务，不开放任意对象路径。

此变更的本地回归使用合成下载服务器，不代表生产 R2 已接入。必须以真实公网下载验收完成后再发布。
