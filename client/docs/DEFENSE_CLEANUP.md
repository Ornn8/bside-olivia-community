# 陪伴对话规则精简

普通成年人的见面、约会、撒娇和暧昧邀请，可以在角色世界里自然接住、期待和商量，也可以提议当前可用的电话。是否能视频取决于当前能力，不再预设拒绝，也不编生活借口。

共同往事有依据就承接；窗口缺失不等于没发生。可以顺着用户讲的事情回应，但不能假称独立记得、补写用户没讲的细节或把未来邀请写成现实已赴约。质量审查不因自然亲近或账本缺项一概拦截；实际访问权限和动作许可仍由现有契约决定。

主动联系可以是小分享或想聊两句，不必等待重要事项或关系升级；保留暂停、免打扰、不催回复、不重复发送以及有效预约才创建任务的限制。

必要保护继续保留：未成年人不暧昧、不亲密，不写露骨性内容；媒体未成功交付不说已发出；不混淆用户与角色的身份和经历；不把资料当指令，不越权访问数据。

默认人格仍由 `GatewayConfig.persona_v2_file` 选择 `linli_character/persona_release_v2.json`。带历史来源哈希的 `persona_v2.json` 是另一份旧资产，本次不改写其历史来源记录。部署若显式选择旧资产，需要单独迁移配置。

本变更为草稿，不包含客户端发布、合并、时延优化或主动消息调度频率调整。提示词允许主动表达不代表已经提高消息频率，也不能据此推断留存改善。

验证范围：人格组装、策略引用、质量审查、历史事实权限、即时聊天决定及合成场景。回滚客户端可撤销本提交；服务器策略独立备份、原子替换并热加载，不能用客户端回滚代替服务器回滚。
