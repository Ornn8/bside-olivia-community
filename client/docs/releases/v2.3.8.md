# Olivia 2.3.8

网络不稳时，打电话更可靠。

## 改进

- **「打电话」按钮不再时有时无**：网络偶尔不稳时按钮会保留，半分钟后自动重新确认，不会再一下消失好几分钟。
- **「用手机打」更容易配对成功**：生成二维码时网络慢会自动再试一次；仍然失败时会提示检查网络，可以直接点「重试」。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.3.8.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后按提示重启 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后如果版本低于 2.3.8，再用上面的补丁更新到最新版。
