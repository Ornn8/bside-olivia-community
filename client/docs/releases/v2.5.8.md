# 2.5.8

登录后，QQ 设置页又能显示正确的状态了。

## 修复

- **QQ 设置页登录后显示正确状态**：QQ 登录成功后，设置 → QQ 页面会显示“已连接”，不再停在二维码或“QQ 已掉线”，也不再提示“state is not defined”。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.8 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
