# 2.5.4

她信里附的视频和歌现在都能打开了；等夜里做的歌时，断网也不会再显示没做出来。

## 修复

- **她信里的视频能看了**：她主动写给你的信里如果附了视频（比如之前没赶出来、后来补做好的歌曲视频），现在信里会显示视频，点开就能看；之前只显示信的文字。已经收到的信，更新后重新打开就能看到。
- **信里也能附上做好的歌**：之前没能送到的歌，补做好后也会随她的信送到，在信纸上直接播放，也可以添加到曲库。
- **等歌和视频时不怕断网**：歌和歌曲视频有时要等到夜里才开始做。等待期间电脑断网或睡眠一会儿，信不会再显示「这次声音或视频未能生成」，会一直等到做好再放进信里。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.4 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
