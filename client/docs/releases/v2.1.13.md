# Olivia 2.1.13

她更像一直陪着你的人了：不再冷冰冰地划清界限，也更容易想起你们以前的信。

## 改进

- 聊到见面、将来这类话题时，她会温柔地接住你的心意，不再说「我们之间没有这一步」这类话。
- 你问起以前的某封信或某件事时，相关的信更容易被想起来；她当前日常生活相关的旧信不会再把它们挤掉。

## 修复

- 「长期记忆 → 信件原文」里，QQ 发的每条消息会出现两次的问题。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.1.13.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后用上面的补丁更新到 2.1.13。
