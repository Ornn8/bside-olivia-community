# Olivia 2.4.4

她的近况更清楚，聊天更自然，彼此的关系也有了更细致的呈现。

## 优化

- **世界页更清楚**：只展示最近三条真实关心的事，简短易读；你说的话和她的经历分开呈现，移除了多余的物品栏按钮。
- **判断更轻快**：把注意力放在近期仍在进行的事情上，减少重复判断，让回应更快。
- **聊天更自然**：减少不必要的防备，自然接住你的关心、玩笑和共同话题。
- **主动联系**：她默认会主动找你，不需要再打开设置开关。
- **关系展示更细致**：可以看到关系路线、不同维度的变化、最近的共同瞬间和未完成的约定。

## 新增

- **删除信件**：可以删除不想保留的信件，相关记忆也会一并清理。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.4.4.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
