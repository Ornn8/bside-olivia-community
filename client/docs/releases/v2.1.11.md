# Olivia 2.1.11

修复聊天记录较长时，QQ 回复显示「这条消息的回复生成失败」的问题。

## 修复

- QQ 聊天记录较长时，偶尔会因为附带的日常小视频素材让内容超出长度上限，整条回复失败。现在放不下时只是这一轮不附小视频，正常回复。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.1.11.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后用上面的补丁更新到 2.1.11。
