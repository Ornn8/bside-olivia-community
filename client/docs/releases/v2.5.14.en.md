# 2.5.14

Fresh installs now check for and install updates automatically too.

## Improvements

- **Fresh installs now check for and install updates automatically too**: after a new install from the installer, or a full reinstall, a copy that had never had a patch applied by hand did not update itself, and you had to download patches yourself. Now it checks, downloads and installs new versions like any other copy. Chat history, memories, Key and settings are kept.

## Updating

Version 2.4.0 and later update automatically: when "Update ready" appears at the top, you can read what's new and restart to update, or let it apply the next time you open the app.
