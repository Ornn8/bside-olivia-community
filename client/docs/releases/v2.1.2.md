# Olivia 2.1.2

修复部分回信修改后仍因轻微风格问题无法寄出的情况，并完善回信失败时的诊断信息。

## 回信与聊天

- 回信修改后，如果只剩轻微的措辞或风格问题，会保留修改后的正文正常寄出，文字信件、语音和聊天使用一致的规则。
- 编造经历、事实错误、越过关系边界等问题仍会拦截，不会因被标为轻微问题而放行。
- 回信或聊天检查未通过时，诊断包会记录具体问题代码，方便排查；不会包含候选正文或审核说明。

## 升级方式

在 **设置 → 更新与帮助 → 选择补丁并更新** 选择本页附件中的 `Olivia-2.1.2.zip`，完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置都会保留。

首次安装或覆盖安装可使用 `Olivia-Setup-x64.exe`。覆盖安装时选择原来的产品目录，即包含 `install` 和 `runtime` 的上一级目录。

Windows 安装器未做代码签名，可能显示“未知发布者”。请核对本页提供的 SHA256 校验文件后运行。
