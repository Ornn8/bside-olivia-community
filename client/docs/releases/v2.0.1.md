# Olivia 2.0.1

本次修复 2.0.0 发布后反馈的问题。

## 客户端修复

- 从 1.x 升级、之前用 DeepSeek 等自填接口写回信、同时已有 Olivia 账户 Key 的用户，更新后启动时会自动用这把 Key 连接回信服务，不需要再手动点“连接并保存”。旧的回信配置另存为 `data/config/llm.retired.json`。此前这类用户升级后寄信会失败，信件显示“寄信通道好像有点忙”。
- 寄信前会检查回信服务是否已连上 Key。没连上时直接提示到“回信服务 → Olivia 账户”点“连接并保存”，不会再生成一封失败的信。
- 寄信前的回信形式判断与正式回信采用同一标准：“给我看看……”、想看样子或照片算图片请求，只有明确要视频、录像才算视频请求。修复想看照片时被提示“开启说话视频”；“你说句话给我听听”这类请求也能正确识别为语音。
- 随信照片的光线与回信描述保持一致，人物姿态自然；回信写正在上课时，照片里会有老师和同学，不再出现空教室、把脚搭在桌上的画面。

## 云端修复（已在服务端生效，无需更新）

- 白天寄出的随信照片被画成夜晚：照片的光线时段改为按北京时间计算。
- 部分账户寄信时提示“回信形式检测失败（JEV_HTTP_ERROR）”，或世界页显示“用餐更新失败（MEAL_DECISION_UNAVAILABLE）”：已解除云端 JEV 判断的试点账户限制。

## 更新方式

已有用户下载 `Olivia-2.0.1.zip` 或 `Olivia-2.0.1.oliviapatch`，在“本地陪伴 → 补丁更新”中导入，完成后完全退出并重新打开 Olivia。更新保留 Olivia 账户 Key、信件、记忆和设置，无需重新导入记忆包。

## 已知问题

- 关闭窗口时选择“最小化到托盘后台运行”后，再次双击桌面图标不会弹出窗口。请点击屏幕右下角托盘里的 Olivia 图标打开；或关闭时选择“直接退出应用”并勾选“记住该设定”。将在后续版本修复。
