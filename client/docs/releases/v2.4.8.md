# 2.4.8

信件和记忆合在一处，删信更干净，更新时不再打断她的回复。

## 新增

- **信件与记忆**：顶部的「信件与记忆」把管理信件和记忆合在一起：可以搜索全部信件原文、勾选删除信件、浏览她记住的事，从一条记忆能直接跳到对应的信；最近删除的信仍可恢复。设置里的长期记忆也能一键打开这里。

## 修复

- **删信更干净**：删除信件时，相关的记忆和原文会一起清理，恢复时完整还原；只删她的回信时，不会再误删你那封信留下的记忆。
- **写过日记的日子也能删信**：可以选择删除当天的日记，并按剩下的内容重新写一篇。
- **彼此的称呼更准确**：关系面板只显示真正的称呼，不再把一整句话当成称呼。
- **更新不打断回复**：重启更新时会等她写完正在写的回复；如果回复被重启打断，会自动重新写好发给你。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.4.8 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
