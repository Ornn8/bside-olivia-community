# Olivia 2.0.0

本次说明汇总自上一发布版 1.3.14 以来的新增功能与修复。

## 只需要一个 Olivia 账户 Key

- 文字回信、JEV 判断、记忆整理，以及语音、照片、歌曲和视频生成，统一使用同一个 Olivia 账户 Key。
- 设置中的“连接回信服务”简化为“连接并保存”，可直接粘贴已有 Key；媒体生成页面只显示连接状态，账户 Key 变化后自动生效，无需另外填写服务地址。
- 移除 DeepSeek、OpenCode Go、阿里云百炼等自填大模型接口，以及自填 GPU 生成服务地址。升级后旧的自填配置会被忽略（文件保留在本机，不会删除），请改用 Olivia 账户 Key。
- 系统环境变量中的其他服务商 Key（如 `DEEPSEEK_API_KEY`、`OPENAI_API_KEY`）不会被读取或发送到 Olivia 服务。首次安装不再询问 DeepSeek key。
- 还没有连接 Key 时寄信，会直接提示先到“回信服务 → Olivia 账户”获取或导入 Key，不会生成一封失败的信。
- 长期记忆组件仍在本机安装和配置，不受影响。
- 实时对话（Live）暂不提供，以后再做。

## JEV 判断链路

- 回复意图、媒体形式、人格信息选择、记忆检索与核验、世界更新、情绪、主动联系及回复复核统一接入 JEV；主回复模型只负责表达。
- 按判断任务只提供必要信息：本次原文、必要提示和少量相关内容，减少重复原文、规则和无关历史；可同时完成的判断合并为一次结构化请求。
- 判断异常会明确记录并显示状态，不会悄悄回退到旧的小模型。
- 媒体预检只判断当前来信需要的回复形式，不再提前执行完整回复计划，修复部分普通信件和语音请求无法寄出的问题。
- 发布版默认连接经过账号认证的云端 JEV 服务，无需配置开发机判断服务。
- 增加按需联网检索判断，只在当前问题确有需要且服务支持时使用。

## 世界与聊天、信件联动

- 回复后单独判断“是否需要更新世界”；已吃完、改变去向、开始或结束活动等信息可进入同一份生活记录。
- 区分打算、正在进行、已经完成和取消，处理“信里说吃完了，世界仍显示在吃”等同步问题。
- 回复使用对应时刻的世界证据，复核课表、地点、活动等冲突；课表是计划，不等于已经出席。
- 为短期活动和事项增加时间边界与进度更新，过时的“明早有课”等事项不再长期占据“最近在忙”；长期练习、创作和共同约定仍会保留。

## 生活事件与用餐

- 世界事件补充发生过程、遇到的问题、结果、角色感受及后续打算，让日常经历影响后续状态与回复。
- 早餐、午餐、晚餐分别记录状态和时间：未到时间、尚未确认、未吃、正在吃、已经吃完，并支持延迟用餐与后续完成。没有证据时不会把“没记录”当成“没吃”。
- 补充角色的学期、课程与上海当地时间、天气；当前课程和下一节课随时间变化，初始学期计划不会无限沿用。
- 在空闲时段结合当前生活、课程、精力和未完成事项选择后续活动；休息加入恢复判断，减少长时间重复同一状态。
- 世界页面分开呈现今天的安排、牵挂与关系、生活记录；课程和用餐按时间排列，区分计划与已发生记录，连续相同活动合并展示。
- 修复世界页面直接显示 JSON、内部字段或含糊说明的问题，“挂心的事”改为描述具体事件。

## 情绪、关系与角色变化

- 情绪综合用户交流、世界经历、身体状态和作息判断，而不只根据用户一句话变化。
- 当前心情与历史情绪变化分开记录，保留原因及来源；缺少有效记录时不再默认显示为“平静”。
- 增加由经历支持的兴趣、偏好变化与关系记录处理，避免一次表达就改写长期设定。
- 人格资料按当前话题选择相关部分；关系事项、共同约定与后续进展保持时间顺序和来源关联，减少旧记录覆盖新状态、事项重复出现的问题。

## 记忆与上下文一致性

- 保留原话、说话人、时间和来源，处理后续更正与跨轮指代；旧说法与后续更正保持关联，避免只找回旧结论。
- 避免把用户经历、角色经历、计划和完成事实混在一起。
- 保留已接收的用户原文，改善未回复输入、跨话题回忆以及记忆写入中断后的恢复；未发送的回复草稿不会当作已经说过的话。
- 信件、QQ、主动联系，以及图片、语音、视频和歌曲，共享本轮选定的人格、世界与情绪依据，减少不同渠道各说各话。
- 附带记忆迁移工具与使用说明，便于处理既有记忆资料。

## 信件与随信照片

- 调整图片、语音、视频请求识别；重新寄信也会经过媒体判断与确认。
- 照片默认收在信纸下方、露出一角，展开、收起与查看大图之间增加动画衔接。
- 调整信纸尺寸和顶部留白；声带选择和“添加到曲库”移到信纸外，减少遮挡正文。
- 音量改为紧凑的展开式控件，更新语音波形样式。
- 改善寄信失败、重新寄信和媒体预检的状态反馈，保留可重试内容，减少长时间卡在等待回信。
- 修复内部判断结果、原始 JSON 和技术说明进入用户可见正文的问题。

## QQ 与主动联系

- 保存 QQ 号后给出明确反馈，区分配置、连接和实际回复状态；首次绑定后自动启动监听，设置页刷新不再打断正在填写的内容。
- 修复接收、生成、媒体处理及后续状态写入中的部分阻塞；生成耗时较长时仍可接收并保存新消息。
- 新消息可在发送前更新本轮回复依据，避免连续追问后仍发送只回答旧消息的草稿；尚未开始处理的消息可在重启后恢复。
- 图片发送确认改为独立的 120 秒等待；确认结果未知时不再误报失败，也不会自动重发。
- 主动联系结合关系、近期交流、生活事件和可分享事项判断时机，尊重暂停联系、待回复、冷却与未回应限制；未读主动信件可在后续聊天中轻量提醒，并避免跨渠道重复提醒。

## 语音与云端调度

- 调整语音的分句和停顿，减少碎片化表达。
- 云端语音模型保持常驻。
- 并行调度扣除已常驻模型的实际显存占用，避免重复预留，同时保留安全余量。
- 文字与媒体分别保留完成状态，避免把部分完成误报为全部成功；演唱、翻唱与原创歌曲接入本轮人格和世界依据。

## 启动体验

- 接入新的 Community 开机动画与配乐，以约六分之一屏幕面积的独立窗口显示。
- 播放结束后停留在最后一帧，等主界面就绪后再退出。
- 修复旧启动画面未替换、残留空白窗口和动画遮挡主界面等问题；更新包会把动画安装到实际启用的版本目录。
- 扩充诊断中的判断、回复和媒体故障信息，便于区分连接、生成、发送与世界写入问题，诊断中不记录密钥和私人正文。

## 更新方式

已有用户下载 `Olivia-2.0.0.zip` 或 `Olivia-2.0.0.oliviapatch`，在“本地陪伴 → 补丁更新”中导入，完成后完全退出并重新打开 Olivia。更新保留 Olivia 账户 Key、信件、记忆和设置，无需重新导入记忆包。之前使用自填大模型接口的用户，更新后请在“回信服务 → Olivia 账户”获取或导入 Key。

JEV 判断和云端媒体生成需要可用的云服务与有效 Key。服务不可用时会显示相应状态；尚未确认的事件或未完成的生成不会被当作已经完成。
