# 2.4.10

彼此的称呼更准确。

## 修复

- **彼此的称呼更准确**：「好吧」这类普通回话、「我是棒球手」这类自我介绍，不会再被当成你们之间的称呼。之前记错的称呼，更新后一天内会自动更正。她也会从最近的聊天里认出你们真正在用的称呼。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.4.10 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
