# Olivia 2.0.5

本次减少林离日常在后台的无意义更新。此前即使你没有来信，林离在“休息”时也会每 30 分钟重新判断一次，并记录一条“休息·暂停”。

## 后台更新更克制

- **同一活动重复时逐渐放慢**：休息、练琴、读书等活动改为 1 小时后再判断；如果判断结果仍是同一活动，下次间隔加倍（1 → 2 → 4 小时，最长 4 小时）。
- **你不在时放慢**：超过 2 小时没有来信或 QQ 消息时，林离的日常改为每 3–5 小时更新一次。你一来信，日常立即按正常节奏继续。吃饭时间、上课时间变化仍会照常更新。
- **没有变化时少做判断**：同一活动重复时，只做一次“接下来做什么”的判断，不再额外判断“这段经历”和“成长变化”。休息仍保留经历判断，这是林离精力恢复的唯一依据。
- **情绪只在交流时评估**：林离的情绪不再在后台随日常更新评估，改为在你来信或发消息时，把这段时间的日常和你的消息一起评估一次。

## 云端修复（无需更新即已生效）

- 修复寄信和 QQ 回复被“请求过于频繁”拦下的问题（信件显示 `LLM_UNAVAILABLE` 或 `JEV_BILLING_UNAVAILABLE`，QQ 显示 `PERSONAL_CHAT_PROVIDER_RETRYABLE`）。此前写回信的频率限制把每次回信所需的多次判断也计算在内，一封信的判断就可能占满一分钟的额度，导致真正写回信的请求被拒。现在写回信与判断分别计数。

## 更新方式

已有用户下载 `Olivia-2.0.5.zip` 或 `Olivia-2.0.5.oliviapatch`，在“本地陪伴 → 补丁更新”中导入，完成后完全退出并重新打开 Olivia。更新保留 Olivia 账户 Key、信件、记忆和设置。

## 已知问题

- 信箱中没有日期的导入旧信仍显示为 1970-01-01（按本机时区显示时间）。这是原版界面对“无日期”的显示方式，不影响回忆。
- 关闭窗口时默认仍是“最小化到托盘后台运行”。如需关闭后彻底退出，请在关闭提示中选择“直接退出应用”并勾选“记住该设定”。
