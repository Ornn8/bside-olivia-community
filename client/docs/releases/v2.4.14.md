# 2.4.14

她想起你们以前聊过的事更准，回复也更快。

## 改进

- **想起以前的聊天更准**：她回想你们聊过的话和记下的小事时，换了一种新的理解方式，更能找到和你这句话真正相关的那几次聊天。
- **回复更快**：每次回复前回想以前聊天的等待，从一两秒缩短到零点几秒，也不会再偶尔卡住几秒。
- **更新后会重新整理一遍**：更新后她会在后台把以前的聊天重新整理一遍，一般不到一小时；这期间她照样记得你们的事。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.4.14 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
