# Olivia 1.3.4

本次更新改进 QQ 消息接收、连接验证和聊天回复，并增强长期记忆离线导入失败时的诊断信息。

## QQ 聊天

- 修复文字带 QQ 表情时整条消息被忽略的问题，纯 QQ 表情也能作为消息接收。
- 连接测试和验证码回复独立处理，不再排在普通聊天生成后面；验证码不会与紧接着发送的聊天内容合并。
- 调整 QQ 回复风格，默认使用简短口语回复，明确要求详细解释时仍可展开。

## 长期记忆

- 离线导入失败时保留更明确的错误分类和失败阶段，方便区分磁盘空间、权限、文件占用和校验问题。
- 导出的诊断包增加脱敏安装状态，便于排查反复提示“需修复”的情况。

## 安装与更新

- 已安装用户可导入 `Olivia-1.3.4.oliviapatch`，完成后完整退出并重新启动 Olivia，无需重新导入已有模型。
- 首次安装可使用 `Olivia-Setup-x64.exe`。
- QQ 首次保存绑定后，按页面提示重启 Olivia；连接验证完成后正常发送聊天消息即可，无需逐条授权。
- 本版本包含 1.3.3 的启动修复、QQ 组件下载通道和此前的照片回信、历史检索及安装体验改进。
