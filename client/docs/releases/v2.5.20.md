# 2.5.20

她主动写的信可以带照片，答应过的事做到了会标成完成，英文界面的通话说英文，超过一分钟的唱歌语音也能听、能唱回，核显笔记本上窗口不再一直黑着。

## 改进

- **她主动写的信可以带一张照片**：写信之前她先判断这封信要不要附一张她此刻的照片；要附的话，信里会自然提到随信的照片，照片做好后连信一起发出。照片没做成或等太久时，信会改写成纯文字再发出，不会出现信里说有照片却没有的情况。
- **答应过的事做到了就算完成**：她答应要发的照片、歌、翻唱、钢琴录音或视频，发出以后「计划中」里对应的事项会标为已完成，不再一直挂着、后来变成「旧事项，进度未确认」；更新后之前已经发出的也会补着核对一遍。
- **英文界面下，通话说英文**：界面语言是英文时，她在通话里用英文回答，也用英文念出来。
- **超过一分钟的唱歌语音也能听、能唱回**：以前超过一分钟的语音会被当成「没听清」。现在最长五分钟的语音会在安静处分段听，她知道一共多长、每一段听到了什么；整段语音会保存下来，她想唱回时整段唱。万一整段唱不了，会挑其中最清楚的一段唱，并告诉你唱的是第几秒到第几秒。
- **笔记本核显下窗口黑屏的问题**：在 Windows 图形设置里把 Olivia 设为「节能」（核显）时，窗口可能一直是黑的。现在每次启动会让两个绘图程序用同一块显卡；窗口一直没画出来时，会用兼容方式自动重启一次。「设置 → 更新与帮助」里新增「兼容显示模式」：自动 / 开 / 关，下次启动生效。
- **启动动画不会一直挂着**：视频播完最多 30 秒（从开始算最多 60 秒）后自动关闭，点一下也可以跳过。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.20 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
