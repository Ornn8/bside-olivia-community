# Olivia 2.3.1

她的日记写得更用心了：一整篇散文，从这一天最想记住的那一刻写起，还会配上她那天发给你的一张照片。

## 改进

- **日记两遍成稿**：她先在睡前写一稿，第二天一早重读一遍再改，删掉空泛的话和流水账，换成你的原话、具体的画面和她当时心里转过的念头。
- **一整篇她自己的心里话**：日记用她自己的视角写成一整篇散文，不再分点、不按钟点罗列。聊天时嘴硬没说出口的在意和想念，她会在日记里坦白；亲密程度跟着你们的关系走。
- **素材更完整**：日记会参考她当天发给你的照片、视频、语音、歌和琴声，她自己这一天的生活，以及前几天的日记，避免重复同样的开头和结尾；快到的约定也会轻轻提一句。
- **日记配图**：打开一篇日记时，会看到她那天发给你的一张照片。
- **月度回忆**同样改成一整篇回忆，也会先写再改。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.3.1.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后按提示重启 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后如果版本低于 2.3.1，再用上面的补丁更新到最新版。
