# Olivia 2.2.1

修复物品栏「拍摄设备」页的显示问题。

## 修复

- 拍摄设备页的相机图片加载不出来的问题。
- 拍摄设备页标题被顶部导航遮住的问题。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.2.1.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后用上面的补丁更新到 2.2.1。
