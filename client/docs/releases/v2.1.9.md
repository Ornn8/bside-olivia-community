# Olivia 2.1.9

修复 2.1.8 更新后 QQ、微信已连接却无法生成回复的问题。

## 修复

- 补齐聊天所需的媒体输入模块。此前 2.1.8 补丁漏带该文件，普通文字聊天也可能显示 `PERSONAL_CHAT_GENERATION_FAILED`。
- 构建时将该模块列为必需文件，并加入打包后聊天流程的检查，避免再次遗漏。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.1.9.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中导入，无需解压。更新完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。

也可以下载 `.oliviapatch`，使用原补丁入口导入。无法启动客户端的用户可用新版安装器覆盖安装到原产品目录，保留数据。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后确认版本为 2.1.9。

当前安装器未做商业代码签名，Windows 可能显示未知发布者；请从项目下载页领取并核对随包提供的 SHA-256。
