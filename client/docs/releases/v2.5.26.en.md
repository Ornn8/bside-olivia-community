# 2.5.26

When saving a long-term memory fails, the reason is now visible in the diagnostic bundle.

## Improvements

- **Long-term memory**: when saving a long-term memory fails, the client now records why in the diagnostic bundle, and memories that used up their retries get one more try each day.

## Updating

Version 2.4.0 and later update automatically: when "Update ready" appears at the top, you can read what's new and restart to update, or let it apply the next time you open the app.
