# Olivia 1.3.3

本次更新修复启动、长期记忆和 QQ 组件问题，并改进照片回信、聊天上下文和安装体验。可直接升级到 1.3.3。

## 本次修复

- 修复更新后双击无反应、启动失败的问题：补齐回信后台依赖的图片模块。
- 修复长期记忆离线包已导入，仍提示组件不可用或“下载管理服务暂不可用”的一项打包原因：Windows 换行转换破坏了锁定清单的校验。继续使用现有离线记忆包，无需重新下载模型。
- QQ 启动改为后台准备依赖，避免启动请求一直等待大文件下载；重复点击复用同一个启动任务，准备失败会显示错误状态。
- QQ 组件改用新的下载通道，无需直接连接 GitHub。首次下载约 427 MB，已安装且完整的文件可以复用。

- [#487](https://github.com/Ornn8/bside-olivia-community/pull/487)：优化 QQ、微信聊天的上下文组织，减少无关历史和重复内容。

## 安装与更新

- 已安装且能启动：导入 `Olivia-1.3.3.oliviapatch`，完成后重启客户端。
- 更新后打不开或首次安装：使用 `Olivia-Setup-x64.exe`；已有用户保留原安装目录和数据，不要先删除用户数据。
- 长期记忆及声音、视频模型仍通过离线包导入。若旧进程仍保留此前的记忆错误状态，请完整退出并重新启动；持续失败时导出诊断包。
