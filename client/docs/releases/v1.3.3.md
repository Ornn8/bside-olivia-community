# Olivia 1.3.3

本次正式版汇总启动、长期记忆和 QQ 组件修复，并包含此前已合并的照片回信、历史检索、缓存及安装器改进。1.3.1、1.3.2 为本地验证版本，正式用户可直接升级到 1.3.3。

## 本次修复

- 修复更新后双击无反应、启动失败的问题：补齐回信后台依赖的图片模块。
- 修复长期记忆离线包已导入，仍提示组件不可用或“下载管理服务暂不可用”的一项打包原因：Windows 换行转换破坏了锁定清单的校验。继续使用现有离线记忆包，无需重新下载模型。
- QQ 启动改为后台准备依赖，避免启动请求一直等待大文件下载；重复点击复用同一个启动任务，准备失败会显示错误状态。
- QQ 组件改由 Olivia 服务签发临时链接，从 R2 下载完整依赖包，不再要求用户直接连接 GitHub。首次下载约 427 MB，已有且校验通过的文件可复用；组件版本及 SHA-256 固定校验。

## 此前 PR 的改进一并包含

- [#488](https://github.com/Ornn8/bside-olivia-community/pull/488)：照片生成完成、跳过或失败后再发布回信；QQ 发信前准备好照片。新安装器补齐 Pillow 图片依赖，诊断包增加脱敏照片任务信息，修正任务状态显示并定时刷新余额。
- [#487](https://github.com/Ornn8/bside-olivia-community/pull/487)：稳定 QQ、微信提示词的可缓存前缀，限制上下文和历史筛选输入规模，分别记录聊天与历史筛选用量。用户单价不变；实际缓存命中与节省以服务端结果为准。
- [#485](https://github.com/Ornn8/bside-olivia-community/pull/485)：先检索历史候选，再由 LLM 选择相关资料，只把选中的原始资料带入回信，减少旧话题干扰当前消息；筛选异常时丢弃可选历史，不回填全部资料。
- [#484](https://github.com/Ornn8/bside-olivia-community/pull/484)：改进安装源自动发现和安装失败诊断，减少手动选择 Steam 目录的需要。
- [#483](https://github.com/Ornn8/bside-olivia-community/pull/483)：修复 QQ 启动依赖，在 Olivia 内展示登录二维码，改进已有进程与登录入口处理。
- [#486 / 1.3.0](https://github.com/Ornn8/bside-olivia-community/releases/tag/v1.3.0)：包含云端照片回信、QQ 图片理解、Suno 原创音乐与统一消费记录等功能。

## 安装与更新

- 已安装且能启动：导入 `Olivia-1.3.3.oliviapatch`，完成后重启客户端。
- 更新后打不开或首次安装：使用 `Olivia-Setup-x64.exe`；已有用户保留原安装目录和数据，不要先删除用户数据。
- 长期记忆及声音、视频模型仍通过离线包导入。若旧进程仍保留此前的记忆错误状态，请完整退出并重新启动；持续失败时导出诊断包。

验证覆盖定向回归、打包校验、隔离组件安装，以及线上下载票据和 R2 分段读取。完整 R2 网络下载及受影响用户电脑上的 QQ 登录仍需实际环境验证；本版不承诺解决所有网络或登录问题。
