# 2.5.13

QQ 里分享歌让她唱，现在她真的会答应并去唱；她也会在 QQ 里发表情包了。

## 新功能

- **分享歌之后说想听她唱，她会先答应，做好后发给你**：把网易云音乐或 B站的歌曲卡片、链接发给她，再说想听她唱，她会先回你一句"这就唱"，翻唱要做一会儿，做好以后把 mp3 文件发到 QQ；没能做成时，她会马上告诉你具体原因和错误码。你不需要先让她"听过"这首歌。

## 改进

- **她在 QQ 里又会发表情包了**：轻松、害羞、感谢、逗你的时候，她会在文字后面配一张表情包；认真聊事情、你难过的时候不会发。
- **只是分享歌，她不会直接开唱**：你只是分享、夸这首歌时，她会告诉你可以唱，问你想不想听。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.13 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
