# Olivia 0.1.469

## 更新内容

- 修复本地 MIDI 演奏视频导入依赖 ffprobe 的问题。基础安装自带 FFmpeg 即可转换并导入已有视频，无需下载整套视频生成模型；没有 ffprobe 时使用兼容转码，导入可能比直接复制慢。
- 导入失败记录具体错误码，区分媒体工具不可用、文件缺失、权限不足、磁盘已满与超时，诊断包不记录源文件名或路径。
- 本地演奏弹窗统一深灰配色，失败详情最多展示三项，避免大量错误撑满窗口。
- 历史记忆允许正常出现“林离”这个名字，保留第一人称要求。
- 角色时间固定为上海北京时间，避免把用户的晚安误当作角色所在地已入夜。
- 补齐 Breeze TTS 失败阶段和固定错误码，修复清理临时文件后诊断信息丢失的问题；补充视频安装失败的组件信息。

## 验证范围

本地复现并修复了无 ffprobe 时的视频导入失败。Breeze TTS 与 LatentSync 短链路完成，输出约 5.5 秒视频，耗时 130.53 秒，音视频轨与完整解码验证通过。这次短链路没有覆盖音乐生成、真实信件路由或用户设备，不能据此认定所有视频回退均已解决。

## 安装

已有用户导入 `olivia-local-backend-0.1.469.oliviapatch` 后重启应用。新用户使用 `Olivia-Setup-x64.exe`。若视频回信仍失败，请在本版重试后导出新的诊断包。
