# Olivia 2.2.8

导出诊断包时可以自己选保存位置，不会再只留下 .tmp 文件。

## 修复

- **诊断包导出失败**：有些电脑点「导出诊断包」后，下载文件夹里只多出一个 .tmp 文件，没有 zip。现在点击后会弹出「另存为」窗口，自己选保存位置；电脑不支持弹窗时，Olivia 会直接把 `olivia-diagnostic-bundle-日期时间.zip` 存进「下载」文件夹，并打开所在位置。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.2.8.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包（2.2.2 版），安装后用上面的补丁更新到 2.2.8。
