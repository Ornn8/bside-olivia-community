# 2.5.21

QQ 里发来的图片她没看到时，会再取一次；还是取不到，她会直接说没看到，不再乱猜。

## 改进

- **QQ 图片没看到时，她会如实说**：QQ 里发来的图片如果当时没能看到，客户端现在会把原因记下来，再取一次图片；仍然失败的话，她在回复里直接说「这张图我没看到」，而不是凭空猜图里有什么。取回来的如果其实不是图片，会自动清理掉。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.21 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
