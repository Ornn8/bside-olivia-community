# Olivia 2.4.0

以后更新不用再手动下载补丁了。

## 新增

- **自动更新**：有新版本时，Olivia 会在后台自动下载并准备好，顶部出现「新版本已准备好」。点开先看这次更新了什么，再决定是否「现在重启更新」；选「稍后」的话，下次打开 Olivia 时生效，或在夜里空闲时自动完成。更新后会告诉你这次更新了什么。
- **更新更安全**：只会安装经过签名校验的正式版本；万一新版本启动不了，会自动退回上一个版本。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.4.0.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后按提示重启 Olivia。聊天记录、记忆、Key 和设置会保留。这是最后一次需要手动更新，之后的新版本会自动更新。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后如果版本低于 2.4.0，再用上面的补丁更新到最新版。
