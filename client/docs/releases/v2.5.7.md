# 2.5.7

QQ 组件起不来、QQ 掉线时，设置页会说清原因。

## 修复

- **QQ 组件被拦截时会自动补文件**：QQ 组件被安全软件拦截、一启动就退出时，会自动补回缺少的文件，并在设置页说明原因，不再隔几秒就重启一次。
- **QQ 掉线时设置页会直接提示**：QQ 掉线需要重新扫码时，设置页会直接提示，不再一直显示“正在重连”。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.7 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
