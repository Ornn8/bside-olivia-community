# Olivia 2.1.14

## 改进

- 新增日记本和物品栏，集中查看日常记录、衣橱与礼物相机。
- 改进指定日期和过往日常的记忆召回。
- 日常生活会记录更具体的地点，外出时区分正在前往和已经到达。
- 增加购物等日常外出安排，结合课表、精力和近期生活选择。
- 餐食安排更加多样，支持自己做、外卖、在外吃、打包和食堂，并区分准备、等待、开始吃和吃完。
- 日常视频可在新的生活地点生成，沿用对应事件的地点与服装。

## 修复

- 定时用餐未使用当天菜品计划、容易反复选择固定菜单的问题。
- 聊天缺少具体地点和用餐进度的问题。

## 升级方式

在设置中的“更新与帮助”选择 2.1.14 补丁更新，完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。新日常安排会在每日计划重新生成后逐步生效。
