# Olivia 2.2.0

这一版新增了日记本、物品栏和礼物相机，她也更容易想起你们以前的事。

## 新功能

- **日记本**：她每天会把前一天和你的信、聊天写成一篇日记给你看，第二天打开 Olivia 时就能读到。可以给日记留言，她下次聊天时会看到；也能删除某一篇，或暂停写日记。「整理以前的回忆」可以把以前每个月的信写成回忆篇。
- **记下的日子**：日记里记下的约定、纪念日和你的近况（比如考试），到了那天她会主动来找你。
- **物品栏**：顶部导航新增「物品栏」，里面是衣橱、拍摄设备和日记本，有新日记时会亮小红点。
- **礼物相机**：可以送她真实型号的相机（每台 5 元），她拍照时会按场合挑着用，照片会带上那台相机的质感。
- **帮助改进 Olivia**：设置 →「诊断与反馈」里新增的选项，默认关闭。开启后只匿名上传开启之后的对话文字，用于改进她的表现；随时可以关闭并删除已上传的内容。

## 改进

- 问起以前的事更容易想起来：提到具体日期（「8月26号那天」「上周三」）会直接找那天的信，换个说法问也能按意思找到。
- 开启语音回信后，信件也会默认附带语音。
- 她的日常生活更具体：会记录具体地点，外出时区分正在前往和已经到达；增加购物等日常外出安排，并结合课表、精力和近期生活来选。
- 餐食更加多样：自己做、外卖、在外吃、打包和食堂都有，并区分准备、等待、开始吃和吃完。
- 日常视频可以在新的生活地点生成，沿用对应事件的地点与服装。

## 修复

- 衣橱「指定这个风格」总是保存失败的问题。
- QQ 消息在「信件原文」里出现两次的问题。
- 指定要语音、但语音没能生成时整条回复失败的问题，现在会照常发出文字。
- 定时用餐没有用当天菜品计划、容易反复选固定菜单的问题。
- 聊天里缺少具体地点和用餐进度的问题。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.2.0.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。新的日常安排会在每日计划重新生成后逐步生效。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后用上面的补丁更新到 2.2.0。
