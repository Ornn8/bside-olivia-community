# 2.5.18

日记会好好分段，没写成的日记和回忆会补写一次；她主动写的信不再丢标题；她发来的歌不再被标成翻唱。

## 改进

- **日记按段落排版**：日记正文现在是一段几句连在一起的话，段与段之间空一行，不再一句一行地排成窄窄的一列；已经写好的日记打开时也会重新分好段。
- **日记更不容易写不出来**：写日记的模型交回的稿子格式有一点偏差，以前就读不了，现在这类稿子大多能直接用；同一天里同一个模型连续失败两次，会换另一个模型继续写。
- **之前没写成的日记会补一次**：最近一周里因为稿子读不了而没写成的日子，以及因此没整理出来的月度回忆，更新后会再试一次（月度回忆在「整理以前的回忆」里再点一下即可）。
- **她主动写的信，标题不再丢**：回答的标题带了代码框、前后多了几句话或分成两行时，也能读出来；实在没有标题时会再问一次，不再一律叫「想和你说说话」。
- **她发来的歌不再标成翻唱**：她主动发来的歌，发到 QQ 的 mp3 文件名和音乐库里的名字就是歌名本身；只有她唱的翻唱才带「（翻唱）」。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.18 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
