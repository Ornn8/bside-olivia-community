# Olivia 2.3.2

第一次打开就能领 Key 开始聊；她唱的歌，人声和伴奏更平衡了。

## 改进

- **第一次打开就能领 Key**：电脑上还没有 Key 时，启动后会先打开「账户」页，点「获取 Key」就能开始；初始设置的「连接回信服务」里也加了「去领取 Key」按钮。记忆包已经随安装包装好，领完 Key 后不再需要额外的设置步骤。
- **新账户的默认模型**：新领取 Key 的账户，回复默认使用 Claude Haiku 5.5，日记默认使用 Claude Opus 5.5，都可以在「账户」里随时更改。已经在用的账户，模型选择保持不变。
- **歌曲人声和伴奏更平衡**：翻唱和原创歌曲混音时，她的歌声会按原曲人声的响度对齐，不会有时盖过伴奏、有时又太小。
- **日常视频分享更多**：她在一天里的不同时刻都可能给你发日常视频，不再在几次之后就只发照片。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.3.2.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后按提示重启 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后如果版本低于 2.3.2，再用上面的补丁更新到最新版。
