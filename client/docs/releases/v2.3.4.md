# Olivia 2.3.4

她主动找你，不再因为某一轮回复没送达就长时间沉默。

## 修复

- **主动联系恢复更快**：QQ 里某一轮回复没能送达后，她的主动联系只会短暂停下，不会再长时间不主动找你。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.3.4.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后按提示重启 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后如果版本低于 2.3.4，再用上面的补丁更新到最新版。
