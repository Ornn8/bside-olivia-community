# 2.4.18

翻唱和原创歌曲排到夜里制作时，不再提示失败。

## 改进

- **歌曲排队不再报失败**：翻唱、原创歌这类要排到夜里集中制作的歌曲，信里会显示「已排进今晚的制作队列」，做好后自动送到。中途关掉电脑也没关系，下次打开会接着等同一首，不用重新开始。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.4.18 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
