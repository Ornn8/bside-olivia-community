# 2.5.22

带图片、语音或视频回信的信，寄出时不再多弹一次确认。

## 改进

- **寄信少一次确认**：写信时带了图片，或者用语音、视频回信，点寄出后不再多弹一次「要寄出吗」的确认，直接寄出。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.22 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
