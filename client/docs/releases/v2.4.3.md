# Olivia 2.4.3

聊天里她更像她自己了，语音通话也能换成会动的她。

## 修复

- **不再把你的话当成自己的话**：她偶尔会照着你刚说的话回你、学你的自称和口头禅，或者把你的安排说成她的。现在她只记住彼此怎么称呼，不会再把你的原话当成自己说过的，已经出现的情况更新后也会自动纠正。

## 新增

- **通话形象**：语音通话时可以解锁她的通话形象，通话界面换成会动的她，表情、眨眼和手势跟着说话变化，问句会歪头，说到开心时会笑。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.4.3.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
