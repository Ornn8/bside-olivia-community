# Olivia 2.0.4

本次修复从官方林离导入的旧信在回忆中被当作 1970 年的信的问题。

## 导入旧信的回忆

- 从官方林离导入的旧信大多没有日期。此前导入时为了保持先后顺序，给每封信记了一个 1970-01-01 起的占位时间，回忆时这个时间被当成真实日期交给林离。林离看到“1970 年”，就会回答“太久远了，细节记不清”，即使原话已经找到。
- 现在这类占位时间一律按“日期未知”处理：林离能看到完整原话，但不会据此判断往事发生在很久以前。已经导入的旧信直接生效，无需重新导入记忆包。

## 云端修复（无需更新即已生效）

- 修复部分来信在“理解来信情绪”一步被判为前后矛盾而整封寄信失败（错误代号 `JEV_AFFECT_INCONSISTENT`）。这类情况现在会整理成一致的判断后照常回信。

## 更新方式

已有用户下载 `Olivia-2.0.4.zip` 或 `Olivia-2.0.4.oliviapatch`，在“本地陪伴 → 补丁更新”中导入，完成后完全退出并重新打开 Olivia。更新保留 Olivia 账户 Key、信件、记忆和设置。

## 已知问题

- 信箱中没有日期的导入旧信仍显示为 1970-01-01（按本机时区显示时间）。这是原版界面对“无日期”的显示方式，不影响回忆。
- 关闭窗口时默认仍是“最小化到托盘后台运行”。如需关闭后彻底退出，请在关闭提示中选择“直接退出应用”并勾选“记住该设定”。
