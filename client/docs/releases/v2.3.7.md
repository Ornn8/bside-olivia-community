# Olivia 2.3.7

用手机也能给她打电话了。

## 新功能

- **用手机打电话**：在电脑上点顶部「打电话」，通话窗口里点「用手机打」，用手机相机扫出现的二维码，就配对好了。以后在手机上打开这个页面就能直接给她打电话。
  - iPhone 用 Safari，安卓用手机自带的浏览器或 Chrome 都可以。按页面提示「添加到主屏幕」后，从桌面图标就能直接打。
  - 在 QQ 等 App 里打开时麦克风可能用不了，请按页面提示改用浏览器打开。
  - 手机打来时由电脑上的 Olivia 接听，她的记忆和今天的生活都从电脑上读取，所以电脑上的 Olivia 需要开着。
  - 和在电脑上打一样：可以选「标准」或「增强」，她按自己当下的状态接听，可以随时插话，通话内容会记进她的记忆和日记。
  - 安卓手机默认用外放，通话中可以点「免提」在外放和听筒之间切换。
  - 已配对的手机列在「用手机打」里，可以随时解除配对；手机页面上也能自己解除。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.3.7.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后按提示重启 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后如果版本低于 2.3.7，再用上面的补丁更新到最新版。
