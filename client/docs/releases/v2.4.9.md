# 2.4.9

补写前几天缺的日记，她的吃饭时间更合理，设置更简洁。

## 修复

- **补写缺失的日记**：前几天没能写出来的日记，更新后会自动补写（最近一周内）。
- **吃饭时间更合理**：电脑关着时错过的饭点，会按原来的安排记为吃过或没吃，不会再挪到紧挨下一顿饭的时候；早餐最晚十点半、午餐最晚四点半开始。
- **设置更简洁**：长期记忆统一在顶部的「信件与记忆」里查看，设置里不再重复显示入口。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.4.9 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
