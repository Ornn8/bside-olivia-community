# Olivia 2.4.2

修复部分照片已经生成，却提示发送失败的问题。

## 修复

- **照片接收**：选择 1K 时，云端有时会返回尺寸稍大的原图。现在可以正常接收，不再因为图片尺寸高于预期而误判失败。

## 已生效的云端修复

以下修复已在服务器生效，无需等待客户端更新：

- **长语音**：修复部分较长回复只读出开头、后续出现异常噪声的问题。
- **回复与图片恢复**：模型返回空回复或图片检查通道异常时，改用可用的备用通道继续处理，减少整条回复失败。

## 升级方式

2.4.0 及以上的用户会收到自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.4.2.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
