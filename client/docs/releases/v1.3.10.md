# Olivia 1.3.10

- 修复 1.3.9 更新包漏带节日模块，导致更新后 Olivia 无法启动的问题。
- 包含 1.3.9 的信件视频遮挡、随信照片下载、中国节日识别和世界动态刷新改进。

**已经更新到 1.3.9 且打不开的用户：**请下载本页的 `Olivia-Setup-x64.exe`，安装到原 Olivia 安装目录。安装过程保留用户数据；安装完成后重新打开 Olivia。不要卸载旧版本或删除安装目录中的 `data` 文件夹。

仍能打开 Olivia 的用户，可在设置中选择本地更新 ZIP 安装 `Olivia-1.3.10.oliviapatch`，完成后完全退出并重新打开。新用户可直接使用安装器。
