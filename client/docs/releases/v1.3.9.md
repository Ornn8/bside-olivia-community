# Olivia 1.3.9

- 修复信件播放视频时被信纸遮挡的问题。
- 点击信件“下载”后，已生成的随信照片会和信纸、音频或视频一起保存到选择的文件夹；再次打开 Olivia 后也能沿用修复。
- 询问日期、节日或节日安排时，林离会按北京时间识别相关中国节日。普通聊天不会因为当天是节日就反复提起；节日信息不代表法定放假安排。
- 世界页面的生活动态会在活跃时段按变化的间隔更新；生成失败后会继续重试，已打开的世界页面也能看到新动态。

已有用户可在设置中选择本地更新 ZIP 安装 `Olivia-1.3.9.oliviapatch`，完成后完全退出并重新打开 Olivia。新用户可使用完整客户端包，解压后运行 `Olivia.exe`；首次使用按引导配置模型服务。
