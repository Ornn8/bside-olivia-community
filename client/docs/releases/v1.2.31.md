# Olivia 1.2.31

- 云端 GPU 可使用 Olivia 账户 Key，与回信服务共用充值余额。旧 GPU 测试 Key 已停用，请在「回信服务 → Olivia 账户」获取或导入 Key，再到「云端 GPU」选择「使用我的 Olivia Key」。
- 沿用现有回信形式设置，寄出前确认云端生成费用上限：音频 ¥1，视频 ¥5。成功按实际资源占用结算并释放差额，云端生成失败释放预留；文字回信另按 Token 计费。
- GPU 设置展示可用余额、预留金额与消费记录。
- 翻唱参数可自定义原曲保留强度与翻唱噪声，默认 0.6 / 0.25；音频与视频翻唱均生效。
- 写信窗口新增「演唱与翻唱」下的原创演唱、歌曲翻唱，保留切换动效和草稿。原创音乐支持描述、编曲规划及音乐参数自定义，推荐 CFG 7、自适应音质引导开启。
- 优化中转错误提示，区分余额不足、认证失败、请求重复和用量待核对，减少重复寄信。

安装前请退出客户端，通过现有补丁导入入口安装。本补丁不包含模型权重。
