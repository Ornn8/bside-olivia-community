# Olivia 2.2.4

修复宠物页打不开的问题。

## 修复

- **物品栏 → 宠物** 页面一直显示「宠物暂时打不开」，现在可以正常领养、喂猫和购买猫用品了。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.2.4.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包（2.2.2 版），安装后用上面的补丁更新到 2.2.4。
