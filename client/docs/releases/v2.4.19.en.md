# 2.4.19

Replies no longer show up as a block of code.

## Fixes

- **Replies shown as code**: A reply occasionally appeared as code like `{"text": …}`. It now shows as the letter itself, with its signature and illustration, and replies that already looked like this are shown properly after the update.

## Updating

Version 2.4.0 and later update automatically: when "Update ready" appears at the top, you can read what's new and restart to update, or let it apply the next time you open the app.
