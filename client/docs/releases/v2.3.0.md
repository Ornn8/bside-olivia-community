# Olivia 2.3.0

可以听她弹钢琴了，也可以把喜欢的 MIDI 曲子交给她；日常视频的分享和发送更可靠。

## 新增

- **钢琴演奏**：在 QQ 或客户端上传 MIDI 后，她会弹给你听，录成可以播放、下载的 MP3。MIDI 可以选择开头、中段或结尾；她也会弹自己写的完整曲子。
- **“TA 给我的曲子”清单**：本地保存你上传的 MIDI 和曲名。她知道你交给她哪些曲子；想再听某一首时，可以直接提起它。找不到或有重名时，她会向你确认。

## 修复

- **日常视频可以再次分享**：同一段日常隔一阵还可以再分享，不会分享过一次就一直消失；跨过零点仍然有效。
- **视频发送不顺时有照片接上**：日常视频没能发出时改发照片，减少只收到文字的情况。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.3.0.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后按提示重启 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后如果版本低于 2.3.0，再用上面的补丁更新到最新版。
