# Olivia 2.3.9

QQ 里她发照片时会先说句话。

## 改进

- **发照片不再只有一张图**：你在 QQ 里想看她的照片时，她会先回你一句（默认是语音），接着把照片发过来，不再只丢一张图一声不吭。
- **照片没发出也不冷场**：照片偶尔没能发出时，她说的那句话照常保留，随后会告诉你这张没发出来。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.3.9.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后按提示重启 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后如果版本低于 2.3.9，再用上面的补丁更新到最新版。
