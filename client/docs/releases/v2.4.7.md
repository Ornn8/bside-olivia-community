# 2.4.7

日记按时写好，等她录歌、拍照的时候也能继续写信。

## 修复

- **日记不再漏写**：用部分模型写日记时，个别日子会写不出来；现在会稳稳写完，最近几天漏掉的日记会在更新后自动补上。
- **等她创作时也能写信**：她在录语音、唱歌或拍你要的照片时，你可以继续写新的信；同一个请求在完成前不会重复开始。
- **删除信件更可靠**：部分信件提示“无法安全重算”而删不掉的情况已修复。
- **她的日常更稳定**：世界里的日常不会再反复卡在同一件事上，事项的名字也更自然。
- **午睡按时结束**：到点的午睡会结束，不会一次次接着睡下去。
- **英文界面更完整**：世界页的日常、地点和作息显示为英文，更新说明也有英文版。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.4.7 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
