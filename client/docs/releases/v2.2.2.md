# Olivia 2.2.2

给林离领养一只猫，看着它慢慢长大；她的衣橱可以挑选和购买新衣服；她会在 QQ 里分享自己此刻的小视频，也更记得你们聊过的事。

## 新功能

- **领养猫**：在 **物品栏 → 宠物** 里为林离领养猫，一共 6 种：英短蓝猫、橘猫、布偶猫、暹罗猫、狸花猫、奶牛猫。每只 9.9 元，最多 3 只。
  - 猫会随时间长大：奶猫、幼猫、半大的猫，两个月后成年。
  - 喂食免费。林离每天会喂一顿，你也可以每天让她多喂两次；成年后胖瘦由最近一周的喂食决定，只有她喂会偏瘦，常加餐会圆滚滚。
  - 每只猫有自己的性格（黏人、高冷、调皮、贪吃），平时待在家里不同的房间。它在林离身边时，会出现在她的照片和日常视频里。
  - 可以给猫买铃铛项圈、针织小毛衣、猫爬架和猫窝，买了会真的出现在照片里。
- **衣橱**：可以免费挑选 3 套衣服，其他衣服每套 5 元永久拥有。新衣服从云端上新，以后上新不需要再更新程序；照片和视频都会穿你选的衣服。
- **此刻的小视频**：QQ 聊天时，林离会像发照片一样，在合适的时候分享自己此刻的小视频。
- **她记得自己的东西**：你送的相机、给她挑或买的衣服、她今天穿的那一身、她的猫和猫用品，聊天时她都知道。
- **回忆更准**：回想过去聊过的事改用云端语义模型，找到相关旧对话的准确率明显提高。这项不额外收费；网络不好时自动使用本机模型。

## 修复

- 聊天记录很长时，普通短消息可能报「输入过长」而发不出去的问题。
- 安装在层级较深的文件夹时，安装可能失败的问题。
- 翻唱/原创页面在确认发送期间改成视频输出，实际却按音频提交的问题。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.2.2.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后用上面的补丁更新到 2.2.2。
