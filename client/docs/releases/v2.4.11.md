# 2.4.11

启动更稳，补写没写成的日记。

## 修复

- **打不开时自己修好**：以管理员身份运行过 Olivia 之后，部分文件可能变成只有管理员能读，之后正常打开就会启动失败。现在以管理员身份打开时会顺手把文件权限恢复原样；如果正常打开时因为这个原因失败，会弹出一次 Windows 的管理员确认，点「是」就能修好并重新打开。
- **启动失败的记录更清楚**：启动失败时，日志会记下缺的是哪个组件、是不是权限问题，方便排查。
- **补写没写成的日记**：最近几天有的日记因为模型的回复格式不对没写成，次数用完后就不再尝试。更新后这些日子会再补写一次。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.4.11 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
