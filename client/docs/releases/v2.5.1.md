# 2.5.1

启动更稳，通话之后的回复和信件里的小毛病也修好了。

## 改进

- **再点一次就回到她身边**：Olivia 已经开着时再点图标，会直接把她的窗口带到前面（包括从托盘里），不再把正在运行的她关掉重开。
- **不再反复修复和重启**：以管理员身份启动的电脑，权限修复只做一次；关闭了 UAC 的电脑不再来回切换启动方式；夜里自动更新重启时会等修复做完，不再误报失败。
- **上次没关干净也能打开**：如果之前的 Olivia 窗口还残留在后台，启动时会先把它结束，窗口不会一闪就退。
- **端口被占时说清楚**：启动用的端口被别的程序占着时，会弹窗告诉你是哪个程序，并记在启动日志里。
- **通话之后回复正常**：打完电话后，她不会再把通话记录当成回复念给你听，通话内容只作为她知道的背景。
- **信件不再留空白**：信里删掉一段内容后，不会再在开头留下一块空白。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.1 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
