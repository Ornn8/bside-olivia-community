# 2.5.17

她回忆旧对话时能带上更多原话；翻唱可以按你说的曲风来；她主动发来的歌会直接发到 QQ。

## 改进

- **回忆起的旧对话写得更紧凑**：想起以前聊过的事时，每段对话改成带日期的短行，去掉了重复的标注，同样的篇幅里能放进更多真正说过的话。
- **翻唱可以按你说的曲风来**：你在 QQ 里让她唱一首歌时，如果顺便说了想要的样子（比如"摇滚版的"、"慢一点，只用钢琴"），她会照你的原话去做；你没说，就和之前一样由她自己安排。
- **她主动发来的歌会直接发到 QQ**：她主动找你并带着一首做好的歌时，歌会像她唱的翻唱一样以 mp3 文件发到 QQ，同时放进音乐库和她的记忆里；没发成的话，会告诉你原因和错误码。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.17 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
