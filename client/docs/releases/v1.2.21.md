# Olivia 1.2.21

本次补丁修复关系系统里一个会导致**正常聊天被误判成冲突、紧张度持续升高**的问题。

## 紧张度误判修复

此前高频聊天本身不会增加紧张度，但每一轮聊天都会进行关系事件判断。用户讲自己的经历时，如果内容里出现“必须”“逼”“骂”“威胁”等词，关系分析模型有概率把父母、老板、前任或其他第三方对用户的行为误认成用户在针对林离施压。

由于每次 `conflict` 会让 `tension +3`，而普通聊天不会自动降低 tension，这类误判在长时间、高频聊天里可能不断累积。

1.2.21 增加了明确的冲突对象判断：

- `linli`：行为明确针对当前对话中的林离；
- `other`：父母、老板、前任、朋友、陌生人等第三方；
- `self`：用户针对自己；
- `unclear`：无法从原文明确定向。

**只有对象明确为 `linli` 时，pressure / denigration / boundary_violation 才能提交为双方冲突并增加紧张度。**

因此以下内容现在不会增加紧张度：

- “我爸以前总逼我按他的想法做。”
- “老板今天当着大家面骂我。”
- “前任以前总说我必须按她安排来。”
- “那时候我一直逼自己做到最好。”
- 转述别人说过的强硬话、威胁或争吵。
- 单纯因为用户短时间发送很多消息。
- 用户正常讲自己的负面经历、工作压力和第三方冲突。

真正直接针对林离的强迫、贬低，或违反她已经存在的明确边界，仍然可以被记录为冲突。

## 回归保护

新增测试覆盖：

- 父母、老板、前任等第三方故事；
- 用户自我施压；
- 转述和引用强硬语言；
- 对象无法确认的内容；
- 缺少或非法 target 的分析结果；
- 连续 20 轮高频故事聊天，即使第一层分析全部误报 conflict，也不能形成关系冲突。

本补丁**没有修改关系分数公式**：真实 conflict 仍为 trust -2、comfort -2、tension +3，明确 repair 仍为 trust +1、comfort +1、tension -2。本次只收紧“什么情况有资格进入 conflict”。
