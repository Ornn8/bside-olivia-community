# Olivia 2.2.5

宠物页的图片回来了；林离回信更专注于你这一条消息；要求的形式暂时发不了时，她会照常回你。

## 修复

- **宠物页图片**：猫和猫用品的图片现在都能正常显示。以后上新品种、换图片都由云端更新，不需要再更新程序。
- **答非所问**：她偶尔会接着回上一条消息，而不是你刚说的这条。现在回信写完会检查一遍，发现在回旧消息就重新写。
- **语音、视频暂时发不了时**：以前这一轮可能整个失败、什么都收不到；现在她会先用文字回你，并说明这次先用文字。
- **此刻的小视频**：她想分享此刻的视频但没能准备好时，这条回复也会照常发出，不再整轮失败。

## 改进

- **照片**：她会更多地发自拍，少拍物件和风景；只有你想看的就是某样东西（一道菜、窗外的景、一只猫）时才拍那样东西。自拍和外出时朋友帮拍的照片，构图、角度和取景都更多样。这项在云端生效，不用更新也能看到。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.2.5.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包（2.2.2 版），安装后用上面的补丁更新到 2.2.5。
