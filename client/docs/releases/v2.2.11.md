# Olivia 2.2.11

QQ 更稳了：连接断开不再丢掉正在写的回复，写好却没发出去的回复会自动补发；以图片为主的回复在重启后也会继续完成。

## 修复

- **QQ 断线后回复丢失**：之前 QQ 连接一断开，她正在写的那条回复会直接作废，你只能重新发消息。现在会继续写完，重新连上后再发出。
- **写好的回复没有发出去**：回复已经写好、但恰好在发送前断开连接时，这条回复会一直停着、不再发出。现在重新连上后会自动发出。已经发出或无法确定是否发出的回复不会重复发送。
- **以图片为主的回复在重启后中断**：她决定用照片回复时，如果中途重启 Olivia 或断开连接，这条回复会停在半路。现在重新连上后会继续完成；已经发出或状态不确定的图片不会重复发送，也不会重复扣费。
- **QQ 被误判离线而重启**：检查 QQ 是否在线时，一次检查失败也会被算作「离线」，可能导致 QQ 被不必要地重启。现在只有连续两次确认离线才会重新登录，检查本身也加了超时。
- **设置页文字看不清**：深色主题下，「信件对比与整理」两栏的标题和日期是黑色的，几乎看不见，现在已修正。感谢 @QiLiangaiBashan 的贡献。

## 说明

- 匿名运行数据（不含聊天内容）会附带更具体的出错类型和 QQ 连接状态，方便维护者定位「收不到回复」「掉线」这类问题。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.2.11.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包（2.2.2 版），安装后用上面的补丁更新到最新版。
