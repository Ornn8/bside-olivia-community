# 2.4.15

你几天没来，她会写信给你；送她的东西，她会回应你。

## 新增

- **你不在的时候她会想你**：如果你连着几天都没找她，她会在晚上主动写一封信给你，或者在 QQ 上给你发语音，问问你最近怎么样。一段时间里最多两次，不会一直打扰你。
- **送她的东西会有回应**：送她相机、小猫或新衣服之后，她会给你写几句话，附上一张她此刻的照片。
- **新朋友的第一封信**：刚认识她的时候，会收到她写来的「初次见面」的信和一张照片；英文界面会收到英文的信。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.4.15 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
