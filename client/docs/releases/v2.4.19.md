# 2.4.19

回信不会再显示成一串带花括号的代码。

## 修复

- **回信显示成代码**：偶尔有回信整封显示成 `{"text": …}` 这样的代码，现在会正常显示信的内容、落款和插画；之前已经显示成代码的回信，更新后也会恢复正常。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.4.19 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
