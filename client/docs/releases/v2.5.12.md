# 2.5.12

QQ 聊天里可以让她翻唱你分享的歌；之前漏记的话，会在后台重新看一遍，补进记忆。

## 新功能

- **在 QQ 里给她分享一首歌，让她唱，她会直接翻唱给你**：把网易云音乐或 B站的歌曲卡片或链接发给她，说想听她唱，她会直接翻唱这首歌，并把成品发回给你。

## 改进

- **QQ 聊天：之前漏记的话会在后台重新看一遍，补进记忆**：QQ 聊天里之前没有被记住的话，会在后台重新看一遍，需要记住的会补进记忆。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.12 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
