# Olivia 1.3.5

## 照片回复

- 修复已开启照片选项时，回复仍误称无法发送照片的问题。
- QQ 确认开始准备照片后会先发送一句等待提示；生成或发送异常时提供反馈。
- 修复记忆处理异常可能阻断照片发送的问题，发送结果未确认时不会自动重复发图。
- 修复使用独立文字模型时，云端图片理解的连接配置。

## QQ 连接与诊断

- QQ 接入林离表情包，按聊天语境和关系选择图片，保留发送间隔与重复发送保护。
- 修复回复或语音中出现 `[QQ表情]` 占位文字的问题。
- 改进回复关联和模型连接验证。
- 保留失败原因，避免重新连接后只显示“已连接”而掩盖回复失败。

## 升级

已有用户可下载本页的 `.oliviapatch` 更新包并在应用中导入。升级前请等待正在生成的回复完成。
首次安装可使用本页的 `Olivia-Setup-x64.exe`。
