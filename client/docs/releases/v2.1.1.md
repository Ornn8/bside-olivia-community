# Olivia 2.1.1

本次让林离生活里的计划和变化记录得更准确，整理失败时不再反复重试；修复部分回信在修改阶段失败，以及语音偶尔被截掉最后半句。

## 林离的生活

- 同一封信或同一段聊天里提到的几件事，现在会先逐件找到原话再核对，计划、完成、取消等变化记录得更准确，不再因为几件事混在一起而整轮作废。
- 判断为无法记录的内容不会再自动重试；网络等临时问题仍会按次数上限重试。
- 只用一两个字提到的事（例如“琴”“猫”）也能对上之前记录的事项。

## 信件

- 修复部分较长的回信在修改阶段失败：修改不再受审核用的篇幅上限限制，并去掉了重复带入的来信原文。
- 回信失败时，信箱会区分“修改失败”和“检查未通过”，诊断包会记录具体失败在哪一步，方便排查。

## 语音

- 修复语音偶尔缺最后半句：语音生成不完整时不再当作成功发出。

## 升级方式

在 **设置 → 更新与帮助 → 选择补丁并更新** 选择本页附件中的补丁包，完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置都会保留。
