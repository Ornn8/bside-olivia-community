# Olivia 2.0.3

本次修复记忆回忆失效导致林离“编造往事”的问题，并让林离记住你们之间的称呼。

## 回忆与编造

- 修复回忆几乎总是失败的问题。此前只要候选的往来记录里有一条空白消息（例如只发了表情或图片），或某段原文过长、句子过多、前后关联过多，整次回忆就会放弃，林离手里没有可核对的原话，于是会记错是谁说的、编出不存在的细节。现在这类情况只会少带一些内容，回忆照常进行。
- 回忆出来的每条原话都标明说话人，林离复述时不得把你说的和她说的颠倒；回信后的质量检查也会把“说话人弄反”“把承诺安到错误的人身上”当作编造来拦截。
- 回忆不可用时，会明确要求林离如实说记不太清或请你提醒，不得指认是谁说的、谁答应的，也不得编造时间、地点、物品等细节。

## 称呼

- 林离会记住你们之间实际用过的称呼：你怎么叫她、你怎么自称（包括落款）、她怎么叫你。称呼只取自你们真实写过的原话，不会凭空编造；有新的称呼时以最近的为准。信件和 QQ 共用同一份称呼记录。
- 回信中不会再把你称为“用户”。

## 寄信更稳定

- 回信后的质量检查改为“先检查、有问题再确认”：大多数回信只需一次检查，检查规模不再随回信长短增长。发现问题时才会追加一次确认。
- 世界状态筛选改为“必需 / 有帮助 / 不需要”三档判断。
- 每轮回复后“是否需要更新世界”的判断并入往来事实核对，少一次判断。
- QQ 连续发来很多条消息、世界事项很多时，各项判断会少带一些较早的内容，不再导致回信失败。

## 诊断

- 信件和回忆失败时，诊断包会记录失败步骤和原因代号（不含信件内容）；回忆记录还会标明本轮是否在问往事、最终是否带上了核实过的原话，便于评估回忆效果。

## 更新方式

已有用户下载 `Olivia-2.0.3.zip` 或 `Olivia-2.0.3.oliviapatch`，在“本地陪伴 → 补丁更新”中导入，完成后完全退出并重新打开 Olivia。更新保留 Olivia 账户 Key、信件、记忆和设置，无需重新导入记忆包。称呼记录从更新后的新往来开始积累。

## 已知问题

- 关闭窗口时默认仍是“最小化到托盘后台运行”。如需关闭后彻底退出，请在关闭提示中选择“直接退出应用”并勾选“记住该设定”。
