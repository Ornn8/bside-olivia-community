# Olivia 2.2.9

修复聊天记录很多的老用户 QQ 经常「回复异常」、收不到回复的问题；重启后不会再有消息一直卡在生成中。

## 修复

- **QQ 经常收不到回复**：聊天记录很多时，她要记住的前文、人设和这轮的回复要求加起来超过了上限，回复就会失败，而且越聊越容易出现。现在会先给必须保留的内容留好空间，再放入前文，不会再因为内容太长而失败。
- **消息一直显示生成中**：Olivia 中途被关闭或重启后，正在生成的那条消息会一直停在「生成中」。现在重新打开后会自动收尾：已经写好的回复会核对后继续处理，不会重复发送。
- **诊断包缺少版本号**：导出的诊断包现在会正确记录完整的版本号。

## 说明

- 聊天记录很多时，她每次回复能带上更多前文，这类回复的单条费用会比之前高一些。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.2.9.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包（2.2.2 版），安装后用上面的补丁更新到最新版。
