# Resonance Edition 1.1.18

本次更新改善模型配置的一致性、世界状态提取和诊断导出。

- 官方 DeepSeek Flash 的文字回信和后台世界任务默认使用 high 思考，输出上限为 10000 token（包含思考与最终内容），减少无上限推理带来的费用风险。已验证的 deepseek-v4-flash 记忆提取路由维持原有 low；用户显式能力覆盖继续优先。
- 模型能力配置贯通回信、记忆和审核调用，减少兼容服务因参数不一致而失败的情况。
- 世界状态更准确地区分个人事实、共同承诺和持续边界：普通回信安排不会仅因被提及就成为长期限制，新增共同承诺不会覆盖原生活事项的类型。
- 诊断导出遇到慢响应或异常的状态探测时，会记录该项不可用并继续保留其余诊断信息，避免整份日志都无法导出。

已有用户下载 `Olivia-1.1.18.oliviapatch`，在设置的补丁更新中导入对应 Manifest SHA-256，更新后完全退出并重新打开程序。新用户使用同页安装器。模型与离线资产未改变，已有离线包可继续使用。

费用会随输入、思考输出和缓存情况变化，本次不承诺固定节省比例。未采用实验中的主动信上下文压缩方案。安装器未做 Authenticode 签名，请使用随包 SHA-256 核对文件。
