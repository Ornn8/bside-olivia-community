# Olivia 2.1.8

本次加入表情包风格包；QQ 能识别语音、视频和 PDF，她也会在日常里给你发小视频；修复切换模型后否认说过的约定、历史导入后关系评估异常，以及辅助判断临时出错时回信中断等问题。官网迁到新地址 https://bside-moon.cn/ 。

## 新地址

- 回信、判断、账单、照片和语音、QQ 组件等官方服务改为通过新域名 `api.bside-moon.cn` 访问，更新后自动迁移，模型选择、Key 和账户绑定都会保留。表情包和衣橱图片也可以从国内节点下载，更快更稳。

## 表情包

- 新增 6 套风格包：手绘、静蓝、唱片、戏剧漫画、奇想漫画和动图。在官网 [表情包页](https://bside-moon.cn/stickers.html) 下载，在设置里点「打开表情包文件夹」，把压缩包里的文件夹整个解压进去，不需要重启。
- 风格包用于 QQ 聊天，信件继续使用线稿。每张图片都按校验值核对，改名或损坏的图片不会被使用。
- 衣橱参考图、收款码等图片改为第一次用到时下载并保存在本机，之后直接复用；默认 108 张线稿随安装器提供，补丁不再重复携带图片。

## QQ

- 在 QQ 私聊里可以直接发语音、短视频和 PDF，她会听完、看完再回复，识别结果也会进入之后的聊天记忆。扫描版 PDF 按原文转写。识别按实际用量计费。
- 她会在起床、洗完澡、吃饭、做家务、散步或购物时，偶尔给你发一段 5–15 秒的小视频，生成期间不耽误正常聊天。
- 你说准备睡觉时，她会先问你想听故事还是轻声 ASMR，直接回答就行，不用说时长。
- 扫码登录的提示写明要用为她准备的 QQ 小号扫码，避免误用主号。

## 记忆与关系

- 切换回信模型后，她不会再否认之前说过的约定：带来源、说话人和时间的关系原话会长期保留，写回信和审核用的是同一份依据。
- 导入历史信件后的关系评估改为逐批累积：旧信最多把关系推到中等，之后靠新的来往慢慢加深；关系阶段不会因为导入而倒退。

## 回信更稳

- 辅助判断或世界资料临时出错时，回信不再中断，会先用文字回复；正文已经写好但核验失败时，重试不会重新生成正文，避免重复扣费。
- 计费确认的响应丢失、或模型服务明确返回临时失败时，会自动重试，最多 3 次，成功只结算一次。
- 改写结果被模型包在 JSON 或代码块里时，会自动取出正文，不再整封失败。

## 照片与音乐

- 照片设置可以选择图片模型。
- 原创歌曲按服务支持的时长和风格给出提示，不会悄悄改掉你保存的设置；余额足够时可以直接开始。
- 修复本地演奏导入后没有进入曲库的问题。

## 诊断

- 世界页读取失败时，诊断包会记录日常生活模块具体在哪一步出错，便于排查。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.1.8.oliviapatch`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中导入。更新完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后用上面的补丁更新到 2.1.8。
