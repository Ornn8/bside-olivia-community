# Olivia 2.1.12

衣橱可以正常指定风格了；开启语音回信后，信件也默认附带语音。

## 新功能

- 开启语音回信后，信件回复默认带一段语音，和 QQ 一样。来信里说明这次只要文字时，仍然只回文字；没开语音回信时不变。

## 修复

- 衣橱里点「指定这个风格」总是提示「没有保存成功」的问题。现在选好风格会立即生效。
- 世界页偶尔因为后台正在写入而读取失败或卡住的问题。
- 部分电脑没有开启 Windows 长路径支持时，安装长期记忆组件失败的问题。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.1.12.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载 2.1.12 安装包，安装后即为最新版本。
