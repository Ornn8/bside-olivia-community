# 2.4.11

Steadier startup.

## Fixes

- **Repairs itself when it won't open**: After Olivia has been run as administrator, some files could become readable by administrators only, and opening it normally would then fail. Opening it as administrator now restores the files' permissions, and if a normal start fails for this reason, Windows asks once for administrator approval — choose Yes and Olivia repairs itself and opens again.
- **Clearer startup records**: When a start fails, the log now notes which component was missing and whether it was a permission problem, which makes it easier to sort out.

## Updating

Version 2.4.0 and later update automatically: when "Update ready" appears at the top, you can read what's new and restart to update, or let it apply the next time you open the app.
