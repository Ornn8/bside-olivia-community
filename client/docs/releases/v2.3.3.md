# Olivia 2.3.3

翻唱时她会亲自唱，并配上重新编曲的伴奏；关系阶段和语音、QQ 回复也更稳了。

## 改进

- **翻唱由她亲自演唱**：翻唱的歌现在由她按原曲的旋律和歌词来唱，伴奏是为这首歌重新编曲的。写翻唱信时多了一个可选的「编曲风格」，可以写下想要的风格和乐器，例如「古风，二胡和竹笛」；不填则按默认风格编曲。
- **主动联系的方式**：她主动找你时，QQ 里发语音，信件只写文字，不附带照片或表情包；会优先用你最常用的方式联系你。
- **桌面写信入口**：桌面端恢复了写信入口，信箱有新来信时会显示红点。

## 修复

- **关系阶段正常显示**：长期相处的用户，关系阶段不再一直停在「尚未确定」，会按你们相处的熟悉程度正常显示。
- **语音不再读到一半就断**：回复里出现破折号或空行时，语音会把它们当作一次停顿继续读完，不再只读到一半。
- **QQ 回复中途卡住会重新请求**：QQ 里的一条回复在生成到一半时卡住，会自动再请求一次，不用你重新发消息。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.3.3.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后按提示重启 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后如果版本低于 2.3.3，再用上面的补丁更新到最新版。
