# 2.5.3

她现在会在需要的时候上网查一查；备份也能把日记和记忆一起带走了。

## 改进

- **需要时上网查一查**：你问到天气、新闻、某个说法是不是真的这类事情时，她会先在网上查一下，再用自己的话告诉你；平常聊天和写信时的日常话题不会去查。查的时候只用你这句话里可以公开的内容，不会带上你们之间的私事。
- **备份带上日记和记忆**：设置里的「导出备份」现在会把她的日记（连同你的留言）、她记下的长期记忆和语音通话的文字一起存下来；换电脑时选这个文件导入，日记和记忆都能接上，已经写好的日记不会被覆盖。聊天记录很多的时候也能完整导出了。
- **不再原样重复上一句**：你只回了个表情或一两个字时，她偶尔会把上一句话原样再发一遍；现在她会接着说点新的。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.3 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
