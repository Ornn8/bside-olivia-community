# 2.4.16

「世界」页不会再把旧状态当成现在；聊天只保留 QQ。

## 修复

- **「世界」页标明旧状态**：网络不稳、一时读不到她的最新近况时，页面顶部会写明下面是几点的状态，不会再把早上的状态（比如「已经睡下了」）一直当成现在显示。恢复后提示会自动消失。

## 调整

- **聊天只保留 QQ**：以前绑定过的其他聊天方式不再连接，QQ 和写信照常使用；她邀请你加好友时也只会问你加不加 QQ。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.4.16 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
