# 2.5.19

她可以把你唱或哼的语音清唱回给你；翻唱可以按原曲编曲来；已经收到的歌不再被一条过期的拒绝挡住。

## 改进

- **她可以把你唱的歌唱回给你**：在 QQ 私聊里发给她一段你唱歌或哼唱的语音（3 秒到 60 秒），她可以自己决定用她的声音把同一首清唱回来（只有人声、没有伴奏），也可以用自己的话婉拒；哼唱时她会为这段旋律写上歌词。结果像翻唱一样以 mp3 发回并加入音乐库；不能唱时只会告诉你一次原因和错误码。
- **翻唱可以按原曲编曲**：你明确说要按原版编曲唱、不要改编时，她会保留原曲的伴奏和调，只把唱歌的人换成她；没提时仍然是原来的翻唱方式。
- **歌已经到了，不再被旧的拒绝挡住**：之前如果她说过暂时不能翻唱，后来歌已经发来或本轮其实可以翻唱，旧的拒绝不再让这次翻唱被判成无效。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.19 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
