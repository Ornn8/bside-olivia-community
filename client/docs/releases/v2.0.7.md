# Olivia 2.0.7

本次修复 QQ 聊天中部分回复发送失败、显示 `PERSONAL_CHAT_DECISION_INVALID` 的问题，并让你约好的联系时间不受林离作息限制。

## QQ 回复

- 林离在 QQ 回复时，可能顺带安排一次之后的主动联系（例如“明天找你”），或根据你的话调整聊天偏好（例如暂停主动联系）。此前只要这类附带设置不合规，整条回复都会作废：比如在深夜把联系时间约在早上 8:30 之前的免打扰时段、偏好变化找不到你的原话依据、时间超过七天。
- 现在只忽略不合规的那一项设置，回复正文照常发送。需要你原话依据、主动联系时不改变你的偏好等保护规则不变。被忽略的设置会记录在诊断中，便于排查。

## QQ 对话更连贯

- QQ 回复前会先理清最近几句里谁说了要去做什么、谁正在做什么：林离自己说过要去做或正在做的事（例如她说去洗澡了）是她的状态，不会再被当成你的动作；你没写主语的关心或建议会被理解为对她说的。

## 更丰富的情绪

- 林离自己的情绪从 6 类扩展到 19 类，覆盖喜怒哀惧和亲近：开心、期待、松了口气、感动、心动、害羞、想你、生气、烦躁、吃醋、难过、失落、委屈、孤单、担心、不安、惊讶、无聊、平静。仍由 JEV 从固定类别中判断。
- 当前心情同时判断强弱，显示为“有点难过 / 难过 / 很难过”，回信时也会参考强弱。
- 原有的情绪记录无需清理，自动对应到新类别。

## 世界页更好懂

- 标题直接说她现在在做什么：在休息时段显示“已经睡下了”并注明她计划的休息时间，半夜聊天时显示“还醒着，在和你聊天”，旧记录显示为“某时在做什么，之后还没有新动态”。
- 心情用自然的说法（挺开心、有点不顺心、有些担心、有点难过、松了口气、平静），原因显示为“因为……，她在意的是……”，不再直接展示消息原文；心情过期后显示为平静。去掉“作息仅供参考”“上次为…当前待更新”“判断于”等系统说法。

## 深夜聊天不再“还没醒”

- 过了林离的计划休息时间还在聊天时，她不再说自己“还没醒”“被吵醒”或借作息打发你；作息只是她的计划，正在回复就说明醒着，可以自然说困了、该睡了。

## 作息可以为约定调整

- 你明确约好的联系时间（例如“明早七点叫我起床”“十一点半提醒我吃药”）现在任何时刻都会安排，到点时即使林离原本在睡觉、上课或忙碌，也会照约定联系你。
- 林离自己发起的主动联系仍只在北京时间 8:30 至 24:00，并照常考虑她的作息。

## 林离的日常更有变化

- 此前林离的活动、饭菜和每件事的经过都来自一份很小的固定清单，于是每天都是“泡绿茶、磨同一首曲子的两小节”，连续出现一字不差的“这一处比开始时顺了一些，仍需再练”。
- 现在每天第一次推进她的日常时，会为当天写一份真实大学生式的安排候选：专业作业、琴房或图书馆、乐团排练、跑腿取快递、洗衣收拾、散步去处，以及三餐的具体吃什么，并参考最近七天做过和吃过的内容避免重复；每件事配有不同的可能经过和结果。之后每个时刻仍由原有判断从当天候选中选择，不增加判断次数。
- 每天多一次文字模型调用；当天候选生成失败时沿用原有清单，一小时后再试。

## 回信插画标记

- 修复回信开头偶尔出现 `[[image:linli-40]]` 这类字样。它是回信时选择插画的内部标记，模型偶尔会写错名字或放错位置；现在无论写在哪里、写成哪种近似形式都会被移除，不会显示在信里，也不会导致 QQ 回复发送失败。

## QQ 回复更可靠

- 回复写好后的质量检查偶尔超时时，只重新检查同一条回复，不再整条重写（此前会延迟几分钟，甚至没有回复）。
- QQ 设置页遇到没有 Olivia 账户 Key 时，直接说明该去哪里处理，不再只显示内部错误代号。

## 诊断

- 回信生成失败（`LLM_PROTOCOL_ERROR`）时，诊断会记录具体原因，例如输出被截断、没有正文或数据格式有误。

## 更新方式

已有用户下载 `Olivia-2.0.7.zip` 或 `Olivia-2.0.7.oliviapatch`，在“本地陪伴 → 补丁更新”中导入，完成后完全退出并重新打开 Olivia。更新保留 Olivia 账户 Key、信件、记忆和设置。

## 已知问题

- 信箱中没有日期的导入旧信仍显示为 1970-01-01（按本机时区显示时间）。这是原版界面对“无日期”的显示方式，不影响回忆。
- 关闭窗口时默认仍是“最小化到托盘后台运行”。如需关闭后彻底退出，请在关闭提示中选择“直接退出应用”并勾选“记住该设定”。
