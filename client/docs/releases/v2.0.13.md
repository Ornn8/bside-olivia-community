# Olivia 2.0.13

本次修复 QQ 掉线后要重新扫码、信里写“语音回复”时整封信失败，并让 QQ 聊天后的记忆整理更及时。

## QQ

- QQ 账号被腾讯踢下线后，Olivia 会自动重新连上 QQ，不再需要重新扫码。只有 QQ 要求重新验证时（例如这个 QQ 号刚在别的设备登录过）才会再次显示二维码。
- QQ 聊天后，长期记忆会先保存，不再被林离日常生活的整理拖慢或耽误。

## 信件

- 在信里写“语音回复”“用语音回我”等，林离会用语音回信，不再整封信失败并提示“寄信通道好像有点忙”。需要在设置里开启语音回信。
- 长信里的约定、计划和关系变化整理得更稳，不会因为信太长而整轮丢失。

## 导入与生成

- 同一封旧信先从 `.soul` 备份导入、再从 JSON 导入时，不再出现两封重复的信。
- 照片、音乐或视频已经在云端生成好，但下载途中断网或客户端重启时，恢复后会直接取回原来的结果，不会重新生成。

## 升级方式

在 **设置 → 更新与帮助 → 选择补丁并更新** 选择本页附件中的补丁包，完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置都会保留。
