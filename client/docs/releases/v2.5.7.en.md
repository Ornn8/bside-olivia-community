# 2.5.7

When the QQ component will not start or QQ is logged out, the settings page now says why.

## Fixes

- **A blocked QQ component is repaired**: when security software blocks the QQ component and it exits as soon as it starts, Olivia now puts the missing files back and explains the cause on the settings page, instead of restarting it every few seconds.
- **The settings page says when QQ is logged out**: when QQ is logged out and needs a new scan, the settings page now says so, instead of showing "Reconnecting" for days.

## Updating

Version 2.4.0 and later update automatically: when "Update ready" appears at the top, you can read what's new and restart to update, or let it apply the next time you open the app.
