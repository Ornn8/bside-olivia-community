# 2.4.6

界面、提示，以及她写给你的文字，现在都可以切换成英文。

## 新增

- **英文界面**：在设置的「语言 / Language」里选择 English，界面和各类提示会切换为英文，随时可以切回中文。默认仍是中文，更新后不会改变你现在的使用；世界页里的日常安排等少数内容暂时仍是中文。
- **她用英文回你**：选择英文后，她写给你的信、聊天回复、日记和其他文字也会用英文；切回中文后恢复为中文。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.4.6 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
