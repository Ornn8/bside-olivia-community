# 2.5.16

她回忆过去的对话更准了：现在按内容检索再精选，而不是靠一次判断去挑。

## 改进

- **回忆过去的对话改为检索加重排**：她想起以前聊过的事时，会先按内容找出最相关的几段，再挑出真正对得上的，代替之前"让模型判断翻哪几段"的做法。回复更快，找不到相关内容时就不硬塞。
- **出问题会自动退回原来的方式**：如果这一步暂时用不了，会自动改用原来的挑选方式，对话不受影响。
- **可以关掉**：设置环境变量 OLIVIA_R3_RECALL=0，或在数据目录的 r3-recall.json 里写 {"enabled": false}，即可恢复原来的方式。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.16 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
