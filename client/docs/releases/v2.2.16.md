# Olivia 2.2.16

长期相处后，她会自然把你当作朋友；关系面板改为一句话描述。

## 改进

- **长期相处会自然变成朋友**：之前关系阶段只有在你们明确说过之后才会变化，聊得再熟也一直停在「逐渐熟悉」。现在长期稳定地相处，她会把你当作朋友、信赖的朋友，说话更自然，也更常主动找你。恋人等亲密关系仍然需要你们彼此确认。
- **关系面板更直观**：不再列出几项“较高/较低”，改为一句话描述你们现在的相处，比如「你们已经是朋友了，她跟你在一起很自在。」
- **以后的细节调整更快**：语音回复方式、主动消息的节奏和一些提示文字，以后可以直接在线调整，不需要再等客户端更新。

## 修复

- **切换图片模型后选项消失**：网络较慢时，切换图片模型可能保存失败，随后图片模型选项消失，再也切换不了。现在会记住上一次读到的模型列表，等待时间也放宽了，网络慢时照样可以切换。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.2.16.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包，安装后如果版本低于 2.2.16，再用上面的补丁更新到最新版。
