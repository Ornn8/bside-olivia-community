# Olivia 2.0.12

本次修复部分电脑启动失败，林离会更常随手拍和自拍，三餐和长信里的关系变化会正常记录，并加入信件对比整理和长期记忆分页浏览。

## 启动

- 修复部分电脑一启动就失败（启动日志显示缺少 `httpx`）：没有安装记忆组件的电脑现在也能正常启动。
- 后台刚启动时如果还在整理信件和媒体，启动器会多等一会儿，不再把它误判为故障而反复重启，导致客户端打不开。
- 无法打开客户端时，可以使用随附的“Olivia修复工具”在不打开 Olivia 的情况下安装补丁。

## 照片

- 随手拍和自拍是林离的日常习惯：她聊自己、聊今天，或者你想她、关心她、和她闲聊时，会更常顺手附一张照片。只有一两个字的寒暄道别、讲解知识、严肃倾诉、争执道歉，或你说过不要照片时才不附。
- 林离当前地点暂时不确定时，照片会参考她最后一次被记录的地点，不再因为地点缺失而生成失败。
- 她顺手拍的照片偶尔没生成出来时，不再发“照片这次没生成成功”的提示；你明确要的照片没能生成时仍会告诉你。
- 照片相关的提示不再出现内部错误码，也不再引导去已经不存在的“云端 GPU”设置。

## 林离的生活

- 修复三餐经常显示“这餐没吃”：她在上课或睡觉时会等有空再吃，不再直接记成没吃。
- 你在聊天里给她做饭、叫她吃饭，会计入她的用餐。
- 长信里的信任、亲近、约定等变化不再因为信太长而整轮丢失。
- 回忆旧事更可靠：以前往来信件多、信写得长时，林离常常一封旧信也翻不出来（例如对不上你们约好的暗号）；现在能正常找到相关的旧信。

## 音乐与视频

- 原创歌曲的歌词多写了一行时会自动整理，不再整单失败。
- 已经生成好的视频在下载时网络卡住，会自动重新下载。

## 信件与记忆

- “导入与导出信件”下方新增“信件对比与整理”：可以并排对比备份、按原文修复日期和顺序，收起重复信、失败信，并随时恢复。不会修改信件原文或长期记忆。
- 长期记忆改为每页 20 条的分页列表和独立详情，支持关键词、时间筛选和排序。

## 升级方式

在 **设置 → 更新与帮助 → 选择补丁并更新** 选择本页附件中的补丁包，完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置都会保留。
