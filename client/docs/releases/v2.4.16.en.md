# 2.4.16

The World page no longer passes off an old status as the present one; chat now runs on QQ only.

## Fixes

- **Old status is marked on the World page**: When her latest update can't be loaded for a while, for example on a shaky connection, the top of the page says what time the status below is from. It no longer keeps showing a morning status (like "Already asleep") as if it were now. The note goes away once it loads again.

## Changes

- **Chat runs on QQ only**: Other chat apps bound earlier are no longer connected. QQ and letters work as before, and when she asks to add you as a friend, she only asks about QQ.

## Updating

Version 2.4.0 and later update automatically: when "Update ready" appears at the top, you can read what's new and restart to update, or let it apply the next time you open the app.
