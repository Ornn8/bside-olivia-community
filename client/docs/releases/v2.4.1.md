# Olivia 2.4.1

修复两个会影响新用户和少数用户的问题。

## 修复

- **主动来信显示**：全新安装的 Olivia 里，她主动写来的信在列表里会显示成普通信件，打开后也看不到语音和歌曲。现在列表里显示标题，打开就是她写给你的信，语音和歌曲也能直接播放。已经安装的用户更新后自动修好。
- **以管理员身份运行后打不开**：曾经用「以管理员身份运行」打开过 Olivia 的话，之后正常打开可能会启动失败（错误码 2）。现在 Olivia 会自动用普通权限启动，不会再出现这个问题。

## 升级方式

2.4.0 及以上的用户会自动更新：有新版本时顶部会出现「新版本已准备好」，点开看完更新内容就可以重启更新，也可以等下次打开时自动生效。

2.4.0 以下的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.4.1.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
