# 2.5.15

分享歌让她唱更稳了：不会再因为一次网络慢就悄悄关掉，也不再随口答应做不到的事。

## 改进

- **翻唱不再因为一次网络慢就悄悄关掉**：之前某次检查翻唱能力时网络慢了一下，翻唱就会被默默当成"不能用"，她也不提。现在只有在你真的分享了歌的时候才会重新检查，普通聊天不会因此变慢。
- **分享的歌会保留，之后再来取**：歌曲链接或卡片发来时如果一时取不到，她会先记着，之后的对话里再去取，不会丢。
- **翻唱做不了的时候，她会直接告诉你原因和错误码**：不再装作没这回事。
- **没有下单就不再空口答应"等会儿给你"**：没有真的去做歌、拍照或做视频的时候，她不会再说"晚点发给你"。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.15 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
