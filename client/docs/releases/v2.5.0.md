# 2.5.0

QQ 上的她更像真人了：会用 QQ 表情、戳一戳、发说说、陪你看 B 站视频，回复也更快了；写信时还能附上图片给她看。

## 新功能

- **QQ 表情和戳一戳**：她看得懂你发的 QQ 表情、商城表情和分享卡片，也会用 QQ 表情回你，或者先戳你一下再说话；你戳她，她也会回应。
- **QQ 状态和空间**：她的 QQ 状态会跟着她正在做的事变化；晚上她会发一条说说，配上当天发给你的照片，顺便换个签名；你的说说她会点赞、评论，你在她的说说下面评论，她也会回复。设置的 QQ 分组里每一项都能单独关掉。
- **陪你看 B 站**：发给她 B 站视频链接或分享卡片，她会把视频看完、听完再和你聊。
- **骰子和猜拳**：你在 QQ 里掷骰子或出拳，她会跟着掷一个、出一拳，也知道谁赢了。
- **她会画画**：有时她会随手画一张小涂鸦给你，QQ 和回信里都可能出现，你也可以直接请她画。
- **信里附图片**：写普通信时可以附上最多 4 张图片（PNG、JPG、WebP），点「添加图片」或在信里直接粘贴都行。她会看着图片回信，图片会像她的随信照片一样放在你的信纸下面。
- **指定衣服**：衣橱里已拥有的衣服下面多了「穿这件」，点一下她今天就穿这一件，照片里也是它。之后再指定一次风格，搭配就交还给她自己挑。
- **新模型**：模型列表里新增 DeepSeek Flash。

## 改进

- **回复更快**：QQ 语音在检查回复的同时就开始生成，和服务器的连接也会复用，等她回复的时间明显变短。
- **照片说到做到**：照片发出以后，她不会再说「还在拍」；只在合适的时候才发照片。
- **夜里也能聊**：半夜给她发消息，她会被吵醒陪你说几句；夜里的照片在家里拍。
- **唱歌的回信说清时间**：请她翻唱或唱歌时，她会在信里告诉你大概什么时候能听到，不会再说没听过你附上的原曲。
- **衣橱图片**：衣橱页面改用压缩后的小图，打开更快。
- **送礼后的回复**：你送她东西后，她的回复会在你们聊天的间隙及时发出，不再等你停下来；QQ 一直没有空当时，改用信件送到。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.0 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
