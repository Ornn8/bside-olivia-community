# 2.4.21

衣橱里可以直接指定她今天穿哪一件，衣橱图片也打开得更快了。

## 新功能

- **指定衣服**：衣橱里已拥有的衣服下面多了「穿这件」，点一下她今天就穿这一件，照片里也是它。之后再指定一次风格，搭配就交还给她自己挑。

## 改进

- **衣橱图片**：衣橱页面改用压缩后的小图，打开更快。
- **送礼后的回复**：你送她东西后，她的回复会在你们聊天的间隙及时发出，不再等你停下来；QQ 一直没有空当时，改用信件送到。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.4.21 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
