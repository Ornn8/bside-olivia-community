# 2.4.5

记住已经完成的约定，把注意力留给眼前的对话，让日常陪伴更自然。

## 优化

- **约定有始有终**：已经完成的约定会保持完成，久远又没有新进展的事项会逐渐淡出。
- **称呼更准确**：关系面板只展示真实的昵称，减少把整句话误当称呼的情况。
- **回应更贴近当下**：更专注于你刚刚说的话，减少突然接起旧消息的情况。
- **日记按天记录**：每篇日记只使用当天的素材，不再混入其他日期的经历。
- **媒体更稳定**：服务短暂重启时会稍作等待并重试，减少声音和视频回复中断。
- **关系面板更稳定**：改善关系更新暂不可用时的处理，让她与你的日常相处更连贯。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.4.5 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
