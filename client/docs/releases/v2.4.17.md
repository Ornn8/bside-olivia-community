# 2.4.17

她会在合适的时候主动提议弹琴或打电话；说话更少重复，提起旧事时间也更准。

## 新增

- **她会主动提议**：在 QQ 上聊天时，如果你正放松、想她，或者想听她的声音，她偶尔会问要不要弹一段给你听，或者打个电话。你答应了她才会弹；电话在软件里点「打电话」就能接通。同一件事几天才提一次，你在忙或者心情不好时她不会提。

## 改进

- **提起旧事时间更准**：她回想以前的信和聊天时，会按实际过去了多久来说，不会再把几周前的事说成「昨天」。
- **少说重复的话**：她会留意自己最近常挂在嘴边的说法，换着说。
- **称呼不再乱跳**：她和你说话时，动作描写里都会用「你」来称呼你。
- **主动来信有了自己的标题**：她主动写来的信会按信里写的事取标题，不再每封都叫「想和你说说话」。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.4.17 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
