# Olivia 1.3.8

- 新增 164 张林离表情包，包括手绘、简洁蓝调、唱片、戏剧漫画、JOJO 气质和动图。回信会按使用次数和上次出现的间隔轮换候选，仍由林离根据内容选择；JOJO 组出现频率较低。
- QQ 和微信私聊约每两三条回复提供一次表情候选，林离可以根据语境决定不发。动图可以作为私聊表情发送。
- 首次保存 QQ 绑定后立即连接；支持将常见表情名称转为 QQ 原生表情，并改善暗色输入框和账号提示。
- 随信照片显示在信纸下方，可点开查看；改善照片状态诊断和连接错误恢复。
- 改善连续信件的近期上下文保留，并调整回信形式判断的等待时间。

已有用户可在设置中选择本地更新 ZIP 安装 `Olivia-1.3.8.oliviapatch`，完成后完全退出并重新打开 Olivia。新用户使用完整客户端包，解压后运行 `Olivia.exe`；首次使用按引导配置模型服务。
