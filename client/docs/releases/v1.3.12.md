# Olivia 1.3.12

本次包含 1.3.10 之后的客户端启动、聊天设置、QQ 回复和记忆组件识别修复。

- 修复部分升级后的前端脚本损坏，导致客户端黑屏或信箱无法显示的问题。
- QQ 和微信绑定入口直接开放，不再要求关系解锁或收到邀请；已保存的渠道选择重启后继续保留。
- 修复 QQ 回复因 JSON 代码框、多余说明字段、表情字段缺失或类型错误而被整条拦截的问题。聊天偏好和定时联系仍需通过原有校验。
- 改善 QQ 生成失败和超时的错误提示，诊断包优先保留近期失败任务。
- 修复图片依赖路径变化后，已安装的记忆运行库被误判为未注册的问题；尚未检测的组件状态不再被诊断包误报为已丢失。

## 更新方式

- 程序能打开：下载 `Olivia-1.3.12.zip`，在“本地陪伴 → 补丁更新”中选择这个 ZIP，完成后完全退出并重新打开 Olivia。
- 程序打不开：下载 `Olivia-Offline-Repair-1.3.12.zip`，完整解压，运行其中的修复工具并选择原安装目录，无需先打开客户端。
- 首次安装或需要覆盖安装：使用 `Olivia-Setup-x64.exe`。覆盖安装请选择原产品目录，安装前完全退出 Olivia。

更新保留已有信件、记忆数据、模型和绑定设置，不需要因本次升级重新下载已安装的离线组件。
