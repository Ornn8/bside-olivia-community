# Olivia 2.0.9

本次让林离在 QQ 日常聊天里更常用短语音，重新整理设置页，并修复她错过饭点后一直不吃、补觉后一直犯困的问题。

## QQ 更常用短语音

- 此前只要你没有明确要语音，林离在 QQ 上几乎总是回文字。
- 现在，你没有要求图片或语音时，她会按聊天内容自己决定：问候、闲聊、安慰、撒娇、晚安等适合开口说的一两句话多用短语音；讲解、步骤、地址、数字等需要你反复查看的内容仍用文字。
- 你明确要语音或照片时仍按要求发送；照片只在你要求或确实需要时发送，不会主动增加。语音发送失败时会自动改发文字。
- QQ 回复时，最近聊天记录和固定规则可以连续几轮直接复用，回复更稳定。

## 设置页重新整理

- 右上角的“云服务”“云端 GPU”“回信服务”合并为一个 **账户** 按钮；打开后可以看到 Key，已有 Key 可在下方导入或更换。云图标表示云同步，即将推出。
- 设置页里 Olivia 的内容分为四组，每组平时只显示一行状态，点开才看到具体选项：
  - **林离怎么回复**：回信能力（纯文字 / 文字＋声音 / 文字＋声音＋视频）、图片、主动写信。
  - **QQ / 微信**：绑定和连接状态，出问题时状态行会变红。
  - **信件与记忆**：长期记忆、导入和导出信件、历史关系评估（自动进行，只在需要时显示“重试”）。
  - **更新与帮助**：补丁更新、导出诊断包；手动校验和回滚上一版本收在“高级”里。
- 回信能力、图片和主动写信的开关点了就生效，不再需要点“保存”；保存失败会恢复原设置并提示。
- 语音、图片和视频都由云端生成，不再显示本地组件的安装页面；也去掉了未接入的云服务登录和与账户重复的“大模型”页。

## 林离的饭和觉

- 此前错过饭点后，旧的“这餐没吃”会一直挡住补餐；熬夜后补觉，精力也可能长时间停在休息。
- 现在下课、精力恢复或你们新的聊天，会让她重新判断要不要补吃一顿；补吃单独记录，不改写之前没吃的记录，也会避开课程和正在进行的补觉。
- 补觉的开始和结果会保存下来，醒来后恢复的精力跨天保留；之后新的消耗才会重新累积疲劳，身体不适等照顾限制不会因为睡了一觉就消失。
- 同一时刻重复打开、刷新或重启不会重复判断。原有存档无需处理。

## 升级方式

在 **设置 → 更新与帮助 → 选择补丁并更新**（2.0.8 及更早为 **设置 → 本地陪伴 → 补丁更新**）选择本页附件中的补丁包，完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置都会保留。
