# Olivia 2.2.12

修复部分用户 QQ 连续收不到回复的问题。

## 修复

- **QQ 连续收不到回复**：她会记住之前答应你、还没做到的事。如果其中某件事对应的那段聊天已经找不回来，之前每一条新消息都会因此失败，而且换模型也没用。现在这件找不回原话的旧事会被放下，这一轮照常回复，后面的消息也不会再被它卡住。你的新消息和仍然能找到原话的事情不受影响。

## 说明

- 匿名运行数据（不含聊天内容）会更细地区分这类问题的原因，方便维护者继续排查。

## 升级方式

已安装的用户：从 [补丁下载页](https://bside-moon.cn/update.html) 下载 `Olivia-2.2.12.zip`，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。更新完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户：从 [下载页](https://bside-moon.cn/download.html) 下载安装包（2.2.2 版），安装后用上面的补丁更新到最新版。
