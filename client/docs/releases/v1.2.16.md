# Olivia 1.2.16

本次修复关系已经达到联系方式邀约条件后，林离仍可能长期不发 QQ / 微信邀约的问题。

- 联系方式资格现在直接以现有关系状态为准：熟悉、信任、自在、亲近四个维度中任意三个达到“较高”（>=70）即可，不再要求升级后额外产生一条隐藏的 `contact_qualification` 互动记录。
- 修复邀约前必须已经配置 QQ / 微信通道的循环依赖。开启主动来信后，林离可以先自然询问是否交换联系方式；用户选择 QQ、微信或两者之后，再按现有流程完成对应通道设置。
- 尚未配置所选通道时仍会进入 `SETUP_REQUIRED`，不会因为关系达标而自动连接账号、绕过授权或自行启用 QQ / 微信。
- 主动来信关闭时仍不会主动发送联系方式邀约；现有未读主动信、发送额度、处理中信件、记忆/世界就绪状态等保护继续有效。
- 已经处于发送中的联系方式邀约会继续锁定重复发送，避免同一邀请并发出现多次。

## 更新方式

下载 **Olivia-1.2.16.zip**，在“本地陪伴 → 补丁更新”中选择该 ZIP。安装完成后完全退出 Olivia 并重新打开，确认当前运行版本为 **1.2.16**。也可以直接选择同版本 `.oliviapatch` 文件。

不需要清空关系、重新导入历史信件或重新下载离线模型。

## 验证

本次修复已通过 Windows / Python 3.12 `public-smoke` 与 Windows 离线安装器构建。新增回归覆盖旧版本用户没有新资格字段、三个关系维度已达标、主动来信开关、尚未配置 QQ / 微信以及重复邀约保护等场景。

云服务版本仍作为独立分支维护，本次本地补丁不合并云服务分支代码。
