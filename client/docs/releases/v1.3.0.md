# Olivia 1.3.0

本次更新加入云端照片回信与新版原创音乐，并统一展示媒体生成和文字中转的消费记录。

- 回信格式可开启图片，支持 1K、2K、4K；QQ 可接收照片回信并理解用户发送的图片。
- 已发送和收到的图片内容可进入记忆与世界状态。场景参考按当前地点选取，在其他地点也能生成照片，不强制套用预设房间。
- 原创歌曲采用 Suno V6 生成，并转换为林离声线。默认目标时长为 3–4 分半，实际以生成结果为准。
- 原创音乐增加进阶设置：标题、目标时长、排除元素、风格遵循度、创意偏离度。音乐描述留空时由林离根据回信规划，填写时优先采用用户设置。
- 原创单曲先预留 ¥3，成功后根据实际时长及小幅随机浮动结算 ¥2–3，释放差额；失败或取消释放预留。历史订单沿用原定价。
- 图片 1K、2K、4K 的单张价格分别为 ¥0.45–0.55、¥0.72–0.88、¥0.99–1.21。视频仍单独显示费用上限。
- 统一账单展示文字中转与 GPU 消费、预留和释放情况，并改进媒体任务恢复和结果交付。
- 保留现有翻唱链路，修复语音分段衔接和视频路径兼容问题。

升级后请重启客户端。新功能需配置可用的云端服务与余额，图片功能默认关闭。自行部署服务的用户需同步更新服务端；使用本机 API 转发时需保持转发程序在线。
