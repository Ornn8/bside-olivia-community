# 2.5.10

日记和月度故事更不容易“写丢”了。

## 改进

- **日记和月度故事遇到写不出时会换个模型重试**：写日记或月度故事时，如果模型这一次没能写出来，会保留原因，下一次尝试自动换一个模型重试，不再反复用同一个模型。
- **其他形式的回复也能当作日记收下**：模型把日记放在代码块里、前后多了几句话，或结尾有些残缺时，只要内容确实是一篇日记，就会被恢复成日记条目；明确的拒绝回复不会被当作日记。
- **日记写不出的原因可以在诊断里看到**：诊断信息里会记下失败的原因、所用的模型和回复大小，不会包含日记正文。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.10 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
