# 2.5.9

她能认出你贴给她的旧信，也能读出信件照片上的字了。

## 改进

- **她能认出你贴给她的旧信**：把你们以前的信整段贴给她，她会知道这是哪一封、谁写给谁、大概是什么时候，再接着聊，不再把它当成一段陌生的文字。
- **信件照片会读出上面的字**：发来手写信、笔记、聊天截图这类以文字为主的照片时，她会读出上面写的内容，而不只是说“这是一张信纸的照片”。
- **没有日期的旧信也能排进当时的时间**：导入的旧信如果没有日期，会按前后有日期的信大致推算时间，她回忆起来更不容易错乱。

## 修复

- **导入旧信后关系天数按旧信的日期算**：搬到新安装、导入了几周的旧信之后，相处的天数会按旧信的日期计入，不再停在刚认识的阶段。整理旧信时遇到临时繁忙，会自动稍后重试，不再中途停下。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.9 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
