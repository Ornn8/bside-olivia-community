# 2.5.27

长信的回复质量检查，在对话很长的账号上不再整封失败。

## 改进

- **回信**：对话和记忆很长的账号，回信写完后的质量检查有时因为内容太多被拒，整封信发不出去。现在会自动改用较新的那部分记录再检查一次，信可以正常发出。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.27 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
