# 2.5.14

全新安装的版本现在也会自动检查并安装更新。

## 改进

- **全新安装的版本现在也会自动检查并安装更新**：之前用安装包全新安装、或者整包重装之后，从没手动打过补丁的版本不会自动更新，只能自己去下载补丁。现在这样的版本也会像其他版本一样，自动检查、下载并安装新版本，聊天记录、记忆、Key 和设置都会保留。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本，以及全新安装后还没有更新过的版本，可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.14 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。装上这一版之后，以后的更新就会自动进行。聊天记录、记忆、Key 和设置会保留。
