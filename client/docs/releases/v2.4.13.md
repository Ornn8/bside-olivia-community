# 2.4.13

日记不再把你们俩写反；新增「重写这篇」。

## 修复

- **日记不再写反**：有些日记会站在你的角度写，把她的名字、她的猫和她发给你的照片写成你的；写反的一篇还会带偏后面几天。现在她写日记时分得清哪些是你说的、哪些是她说的，写完还会再核对一遍，看出写反了就重新写。
- **记下的事不再颠倒**：像「谁叫谁什么」这样的小事会按原话是谁说的来记，已经记反的会自动改正。
- **新增「重写这篇」**：打开一篇日记，点「重写这篇」并确认，她会照着这天的信和聊天重新写一篇。原来那篇会换成新写的，你的留言会留着。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.4.13 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
