# Olivia 1.2.17

本次补丁合并了两部分更新：历史信件连续性修复，以及 QQ / 微信首次绑定入口。

## 历史信件连续性

- 修复导入历史信件已经被林离本人明确承认过，但最终回信仍可能因为来源标记为 `untrusted` 而否认这段共同经历的问题。
- 现在会区分“林离本人确认过的历史”“仅用户陈述”“尚未发生的计划”和“存在冲突或后续更正的记录”。只有经过校验、确实来自林离历史回信的内容，才会进入已确认的角色历史连续性。
- 已确认的共同历史不会仅因为来自导入档案而被自动降级；但这不等于把历史信件当作外部世界事实，也不会因此自动改变当前关系权限、现实状态或行动许可。
- 计划、单方面陈述和互相矛盾的记录继续保留原有限制，不会被误当作已经发生的共同经历。

## QQ / 微信绑定

- 用户在联系方式邀约中选择 QQ 或微信后，现在可以直接在现有设置页完成对应绑定，不再需要手动准备隐藏配置。
- 微信支持在本地生成二维码、显示扫码状态，并在需要时输入验证码。二维码内容在本地编码，不额外引入二维码运行时依赖。
- 微信登录凭据完成后使用 Windows DPAPI 保存在本机；状态接口不会返回轮询标识、验证码或最终凭据。
- QQ 目前仍为实验功能，使用 NapCat / OneBot。保存前会先连接本机回环地址并验证机器人 QQ 号，Token 仅以 DPAPI 加密形式落盘，不写入明文配置。
- 只有用户已经明确接受对应联系方式后才允许配置该渠道；不会自动连接账号或绕过用户选择。
- 新绑定完成后需要完全退出并重新打开 Olivia，现有聊天监听生命周期本次没有改成热加载。
- 原有 `olivia-companion-settings.js` 保持字节不变；绑定界面使用独立事务补丁注入，避免破坏旧客户端设置页兼容性。

## 更新方式

下载 **Olivia-1.2.17.zip**，在“本地陪伴 → 补丁更新”中选择该 ZIP。安装完成后完全退出 Olivia 并重新打开，确认当前运行版本为 **1.2.17**。也可以直接选择同版本 `.oliviapatch` 文件。

不需要清空关系、重新导入历史信件、重新建立记忆索引或重新下载离线模型。

## 验证

本次整合版本在 Windows / Python 3.12 上通过完整 `public-smoke`：**4064 passed，8 skipped，1 deselected**；repository hardening 与 whitespace 检查通过。Windows 离线安装器构建、失败边界和校验和验证也全部通过。

新增回归包括：历史中由林离本人确认的共同经历、用户单方面陈述、未完成计划、冲突/更正记录；微信二维码 OpenCV 实际扫码回读；微信状态脱敏；QQ 本机账号验证与明文 Token 禁止落盘；以及旧设置脚本字节保持不变的兼容性检查。
