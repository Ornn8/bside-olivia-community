# 2.5.23

网络慢时，她不会再误说翻唱服务连不上。

## 改进

- **网络慢时翻唱不再误报连不上**：网络慢时，她不会再误说翻唱服务连不上：客户端会记住上次读到的服务功能，重启后继续使用，有歌在等时也会多等一会儿。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.23 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
