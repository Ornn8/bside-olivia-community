# Olivia 2.1.5

优化账户页面的回信模型说明，以 Gemini 3.8 Flash 为 1 倍展示各模型的输入、输出消费倍数。

## 模型选择

- 在 **设置 → 账户 → 回信模型** 中选择 Qwen3.8 Flash、Gemini 3.8 Flash、Claude Opus 5.5、Claude Sonnet 5.5、Claude Opus 4.6 或 Qwen3.8 Max。
- 默认使用 Gemini 3.8 Flash，手动选择后保留所选模型。
- 每个选项只展示输入、输出消费倍数，实际消费取决于用量；短请求可能受最低计费规则影响。
- 选择后点击「使用所选模型」，下一次发送生效。重新连接账户仍会保留选择，切换失败时继续使用原来的模型。
- 使用现有 Olivia 服务账户即可切换，不需要填写新的供应商 Key。

## 升级方式

在 **设置 → 更新与帮助 → 选择补丁并更新** 中选择本页附件的补丁包，完成后完全退出并重新打开 Olivia。聊天记录、记忆、Key 和设置会保留。

新用户可以下载本页附件中的 `Olivia-Setup-x64.exe` 安装。
