# 2.5.2

之前没赶出来的歌曲视频，补做好以后会随她的信一起送到。

## 改进

- **补做好的视频随信送到**：如果你点的歌曲视频当时没能做出来，之后补做好时，她会写一封信，把视频附在信里，打开信就能看。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.2 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
