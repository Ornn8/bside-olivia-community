# Olivia 2.0.6

本次修复最近林离回信变得冷淡、带攻击性的问题，以及部分用户 QQ 和回信报 `JEV_BILLING_ACCOUNT_UNAVAILABLE` 的问题。

## 回信语气

- 林离的“当前心情”此前可以选择“此前的心情仍在延续”作为依据，一次烦躁之后会被反复沿用，整天保持烦躁，回信随之变得冷淡甚至挖苦。现在心情必须有新的具体依据，会随时间自然平复；已过期的心情不再交给回信。
- 回信时明确要求：心情只影响语气轻重和关注点，疲惫、烦躁、失落都不能迁怒你，不嘲讽、不贬低、不挖苦、不攻击你，也不因此对你冷淡或说教。

## 账户 Key

- 如果粘贴 Olivia 账户 Key 时带进了首尾空格或换行，账户页能正常显示，但 QQ 和回信会报 `JEV_BILLING_ACCOUNT_UNAVAILABLE`。现在读取和导入 Key 时会自动去掉首尾空白。

## 语音要求

- 信里说“想听见你的声音”“想听你说话”时，即使写在思念的话里，也会按语音要求用语音回信（需已开启语音回信）。QQ 中同样按语音要求处理（云端已生效）。

## 云端修复（无需更新即已生效）

- 修复部分用户寄信失败、显示 `JEV_BILLING_UNAVAILABLE` 的问题。

- 来信意图较多时不再因“意图过多”（`JEV_PLAN_INTENT_CAPACITY`）而寄信失败。

## 更新方式

已有用户下载 `Olivia-2.0.6.zip` 或 `Olivia-2.0.6.oliviapatch`，在“本地陪伴 → 补丁更新”中导入，完成后完全退出并重新打开 Olivia。更新保留 Olivia 账户 Key、信件、记忆和设置。

## 已知问题

- 信箱中没有日期的导入旧信仍显示为 1970-01-01（按本机时区显示时间）。这是原版界面对“无日期”的显示方式，不影响回忆。
- 关闭窗口时默认仍是“最小化到托盘后台运行”。如需关闭后彻底退出，请在关闭提示中选择“直接退出应用”并勾选“记住该设定”。
