# 2.5.5

她的歌又能添加到曲库了；带视频的信也保留她写的话。

## 修复

- **她的歌能添加到曲库了**：信里她唱的歌，点「添加到曲库」之前会提示添加失败，现在可以正常添加。之前没加上的歌，更新后再点一次就行。
- **带视频的信也有她写的话**：她主动写给你的信里附了视频时，视频下面会接着显示信的文字、署名和时间；之前只有视频，信的内容看不到了。
- **信和回复开头不再出现多余的标记**：偶尔信或回复的开头会多出一行类似 `[语音回复 {...}]` 的方括号内容，还会被读进语音里。现在这类内容会被去掉，QQ 表情和普通的方括号不受影响。

## 升级方式

2.4.0 及以上的用户会自动更新：顶部出现「新版本已准备好」后，可以查看更新内容并重启更新，也可以等下次打开时生效。

较早版本可从 [补丁下载页](https://bside-moon.cn/update.html) 下载 2.5.5 补丁 ZIP，在 **设置 → 更新与帮助 → 选择补丁并更新** 中直接选择，无需解压。聊天记录、记忆、Key 和设置会保留。
