# Olivia 2.0.8

本次主要解决 QQ 聊天“时不时回复不了”，并保证你要语音时林离一定用语音回复。

## QQ 回复更稳定

- 此前 QQ 回复约有三分之一的输出格式不合规（把回复包进数组），重试一次仍可能失败，表现为偶发发不出去、诊断显示 `PERSONAL_CHAT_DECISION_INVALID`。
- 现在 QQ 回复的固定规则放在对话开头，只在你的消息旁保留一句简短提醒；在 24 段模拟对话、每段 3 次的对比中，格式合规率从约 67% 提高到约 96%，回复内容质量不变。
- 模型偶尔把一条完整回复包在单项数组里时，也会照常发送。

## 要语音就发语音

- 你要语音（“发条语音”“好想听听你的声音”“用语音跟我说晚安”）且当前可以发语音时，林离会直接用语音说话，不再在语音里说“不想发”“没空发”“等下再发”。
- 要照片时照片照常生成并发送；服务端同时修复了少数媒体请求因规划不一致而整条失败的问题（无需更新即已生效）。

## QQ 回复更高效

- QQ 回复中每轮都相同的规则现在放在可缓存的部分；模拟对比中，可缓存的输入比例从约 38% 提高到约 55%。

## QQ 设置页

- 连接好 Olivia 账户 Key 后，之前“读不到 Key”留下的旧报错会自动消失，不再误导你以为仍未连接。
- 其他报错下方会注明“这是某月某日某时那条消息的失败”，提示发一条新消息确认是否已恢复。

## 升级方式

在应用内检查更新即可，或下载本页附件中的补丁包覆盖安装。聊天记录、记忆和设置都会保留。
