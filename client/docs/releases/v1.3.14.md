# Olivia 1.3.14

- QQ 语音支持优先调度，有可用并行资源时可以与其他媒体任务同时处理。
- QQ 照片与语音提交不再等待客户端共用媒体锁，去掉重复的“准备照片”固定提示。
- 修复长视频生成完成后因累计等待时间耗尽而校验失败，以及客户端等待过久主动取消视频任务的问题。
- 包含近期日常回复多样性、QQ 媒体选择与表情使用改进。

已有用户下载 `Olivia-1.3.14.zip`，在“本地陪伴 → 补丁更新”中导入，完成后完全退出并重新打开 Olivia。补丁更新保留 Key、信件、记忆和已有设置，无需重装或重新导入记忆包。

QQ 语音优先调度需要更新后的客户端与支持该功能的云端服务共同生效。视频、语音和照片仍可能因服务不可用或生成错误而失败；本次取消的是视频累计执行时长限制。
