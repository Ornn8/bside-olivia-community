# 信件删除与恢复（Draft）

信箱顶栏的“信件与记忆”窗口（“信件”标签）可分别删除你的信、她的回信和她主动寄来的信。删除去信不会同时移除已有回信；尚未回信时删除会取消待处理任务。没有新增或编辑信件功能。

同一个窗口里还有“记忆”标签（长期记忆的浏览、搜索、更正，以及“更多”里的记忆管理）和“最近删除”标签。“信件”标签的搜索框可搜索全部信件原文、读取完整原文；搜索结果只用于阅读，删除只在信件列表里进行，删除的范围、确认和接口都没有变化。记忆里的“查看关联原文”会切到“信件”标签，显示那条记忆来自的信件。

删除前会提示关联记忆也将清理。使用信件 ID、接收原文 ID、历史导入来源及关系证据引用确定范围，不按正文相似度删除。多来源记录保留其他来源，原文按说话人清理；由你自己的话生成的记忆只随“我的信”清理，单独删除她的回信不会清理它们。支持本地 SQLite 档案、原文索引、生活事项、候选记录、可重放的关系证据（含关系瞬间的引文和尚未交给关系批处理的回合）、本地 Qdrant 语义记忆，以及 Mem0 自带的变更历史（其中保存着每条记忆的原文）。

## 恢复与保留期

- 删除意图和受影响记录的前后版本先进入本地状态文件的 `letter_trash`，再修改存储；备份不参与检索。
- “最近删除”保留 30 天。启动后、运行期间每小时及进入管理操作时清除到期备份。关闭应用期间不运行清理，下一次启动时处理。
- 旧格式将部分记忆归因于整轮往来，因此恢复需确认：这轮仍在保留期内的已删除信件会一起恢复，按删除顺序逆序还原记录。
- 最近删除里的各条可按任意顺序恢复。较晚的删除可能改写了与较早一条相同的记录（共享的事项、关系数值），所以恢复较早的一条时，会先按相反顺序撤销较晚的删除，恢复这一条之后再重新清理它们；它们的删除时间和 30 天期限不变。
- 新记录与备份冲突时停止恢复，不覆盖新数据；可以保留备份后进一步处理。
- 中断的清理或恢复不会按保留期丢弃。最近删除保留重试入口，未完成时暂停后续回复，避免使用部分清理的记忆。
- 过期清理是应用层删除，不承诺对文件系统或 SQLite 空闲页作取证级擦除；独立导出的备份也不在本操作范围内。

## 安全限制与尚未完成的范围

这份 Draft **尚未覆盖所有历史数据**。以下情况在修改任何存储前返回明确错误：

1. 相关旧日记或月度回忆没有逐封信的来源标识。整篇删除会影响其他信件，保留则无法保证清理完整，故暂不执行删除。
2. 旧关系账本存在不可重放的状态，或相关重放包含交错、重复证据，无法可靠移除单封信的贡献。
3. 已存在的记忆或世界数据库暂不可用，或配置指向远端向量库。

另有一项不会返回错误、但尚未覆盖：导入的旧信由关系评估整批判断（五封一批）。尚未评估的批次会去掉被删的这一封，之后不会再被评估；已评估的批次里，被删信件的文字会被抹去，但它们整体给出的关系数值（熟悉度、信任等）仍保留，因为这是对整批信件的一次判断，无法在本地拆开重算。这类旧信的关系影响目前不会随删除撤销，是否改为拒绝删除或重新评估，需要另行决定。

这些限制需要补齐历史来源迁移与更完整的关系重放后才能解除，不能将本实现描述为所有信件均可删除、全部历史记忆均能清理。

本功能仅操作本机存储。

## 本地接口

三个接口均为 `POST`，沿用本地确认头 `X-Olivia-Companion-Action: confirmed`：

| 路径 | 请求 | 用途 |
| --- | --- | --- |
| `/toy/letter/deletion/delete` | `{letter_id, part: "user" 或 "reply"}` | 删除指定一侧；同一操作可重试 |
| `/toy/letter/deletion/list` | `{}` | 查看本用户仍可恢复或待完成的操作 |
| `/toy/letter/deletion/restore` | `{id}` | 恢复该轮仍保留的删除备份 |

成功状态为 `DELETED`、`READY`、`RESTORED`，只用于这些新增本地接口，不改变已有信件状态枚举或云端接口。具体错误通过 `data.error_code` 返回，UI 使用中文解释。

验证包括双方独立删除、待回复删除、持久化重启、历史导入格式、来源隔离、多来源保留、恢复、保留期、中断恢复、原文防止重新索引、本地向量库分页与 UI 确认取消。全量测试结果另见任务结果报告。端到端测试（`tests/imports/test_letter_delete_end_to_end.py` 及其浏览器版本）启动真实的本机服务，用合成信件走完发信、记忆写入、关系批处理，再通过窗口使用的接口删除和恢复，并逐个存储对照前后变化；它需要 Mem0 与 Qdrant，可用环境变量 `OLIVIA_E2E_MEM0_SITE` 指向它们所在的目录。
