# Changelog

每个版本的完整内容、升级方式和已知问题见 [`docs/releases/`](docs/releases/) 下对应的更新说明；附件以 [GitHub Releases](https://github.com/Ornn8/bside-olivia-community/releases) 为准。

## 2.1.3 - 2026-10-04

修复部分回信寄不出去和部分电脑启动报错码 2；照片默认开启；历史关系评估与曲库导入出错时显示具体原因。详见 [2.1.3 更新说明](docs/releases/v2.1.3.md)。

- 回信只剩个别找不到出处的句子时，去掉这几句照常寄出；普通消息不再被误判为不用回复。
- QQ／微信回复准备并行、复用已完成阶段；默认语音最多等 60 秒后先发文字；生成失败会提示。
- 照片描述与后台整理检查失败时不再反复付费重试。
- 照片默认开启（按图片计费，可在设置关闭，已关闭的保持关闭）。
- 修复界面补丁冲突导致的启动错误码 2。
- 历史关系评估自动收缩过长输入并保留失败原因；曲库导入显示具体原因；诊断包保留出错记录。

## 2.1.2 - 2026-10-03

修复部分回信修改后仍因轻微风格问题无法寄出，完善回信失败时的诊断信息。详见 [2.1.2 更新说明](docs/releases/v2.1.2.md)。

## 2.1.1 - 2026-10-03

林离生活里的计划和变化记录得更准确，整理失败不再反复扣费；修复部分回信在修改阶段失败与语音偶尔缺最后半句。详见 [2.1.1 更新说明](docs/releases/v2.1.1.md)。

- 往来事实先逐件定位原话再核对，确定无法记录的不再自动付费重试；单字主题也能对上已有事项。
- 回信修改使用独立篇幅预算并去掉重复来信；失败时区分修改失败与检查未通过，诊断包保留失败阶段。
- 语音生成不完整时不再当作成功发出。

## 2.1.0 - 2026-10-03

新增 QQ 睡前故事与 ASMR 音频；林离能更准确地想起以前约定过的事；长期使用后生活和关系变化不再停滞。详见 [2.1.0 更新说明](docs/releases/v2.1.0.md)。

- QQ 里可以请林离讲睡前故事或 ASMR 陪伴，生成 1 到 10 分钟的 MP3 文件，支持五种环境声和续讲。
- 直接提到某件事的旧信会优先被找回（如约定的暗号）；回复中的事实统一核对来源，长语音发送前先审核。
- 已结束两周以上且未提到的事项不再参与核对；整理失败的信每次启动最多重试 3 次；QQ 积压超过 6 小时不再补做日常整理。
- 修复工具不会再把已安装的新版本降级。

## 2.0.13 - 2026-10-02

修复 QQ 被踢下线后要重新扫码、信里要求语音回复时整封信失败；QQ 聊天后记忆先保存。详见 [2.0.13 更新说明](docs/releases/v2.0.13.md)。

- QQ 账号被踢下线后自动重新登录，不再需要扫码；QQ 聊天后长期记忆先于日常生活整理保存。
- 信里写“语音回复”时用语音回信，不再整封失败；长信里的约定和关系变化整理更稳。
- 旧信先后从 `.soul` 与 JSON 导入不再重复；云端已生成的结果在断线或重启后直接取回，不重复扣费。

## 2.0.12 - 2026-10-02

修复部分电脑启动失败；林离更常随手拍和自拍；三餐、长信里的关系变化和旧信回忆恢复正常；新增信件对比整理与长期记忆分页浏览。详见 [2.0.12 更新说明](docs/releases/v2.0.12.md)。

- 修复缺少 `httpx` 导致的启动失败；启动器不再把刚启动、正忙的后台误判为故障；打不开时可用“Olivia修复工具”离线安装补丁。
- 照片：随手拍和自拍默认会附；地点不确定时参考最后记录的地点；顺手拍失败不再发提示；提示不再出现内部错误码。
- 三餐不再被直接记成“没吃”，你给她做饭、叫她吃饭会计入；长信里的关系变化和旧信回忆不再因篇幅过长而失败。
- 原创歌曲歌词多一行时自动整理；生成好的视频下载卡住会自动重下，不重复扣费。
- 新增“信件对比与整理”；长期记忆分页浏览；账单每笔显示时间。

## 2.0.11 - 2026-10-01

修复开启图片后普通信一直"回信中"；QQ 重启后不用重新扫码；减少挖苦式回复。详见 [2.0.11 更新说明](docs/releases/v2.0.11.md)。

- 修复 2.0.10 开启图片后，没有特别要求媒体的信一直停在"林离回信中…"不送达；升级重启后卡住的信会继续送达。照片计划改由服务器完成。
- QQ 会记住登录过的账号，Olivia 或 QQ 组件重启后自动快速登录，不再需要重新扫码。
- 林离可以不同意、拒绝或调侃，但不再挖苦你真诚表达的委屈和请求，也不再把她自己的话当成你的说法反驳。
- 诊断包总会带上最近的几封信。

## 2.0.10 - 2026-10-01

林离重新会在合适的时候顺手发照片；修复回复里念出聊天记录格式、重复上一句；启动画面不再置顶。详见 [2.0.10 更新说明](docs/releases/v2.0.10.md)。

- 开启图片后，你没有特别要求媒体时，林离会按回信内容判断是否顺手附一张她此刻的照片（寒暄、道别、讲解、严肃倾诉时不附）；照片类型会按内容选择自拍、镜前照或景物。
- 回复里不再出现 `[历史消息 …]` 这类记录格式；和最近几条回复一字不差时会重新生成。
- 回忆旧事时，暂存记忆关联失败不再让整轮忘掉所有旧记忆；诊断包记录回忆失败的具体环节。
- QQ 普通聊天默认用语音回复，合成失败时仍发出文字；设置里的文件导入支持灵离 `.soul` 备份。
- 启动画面不再始终置顶；QQ 组件改为在后台启动，不再拖慢启动；诊断包会记录启动各阶段耗时。

## 2.0.9 - 2026-10-01

QQ 日常聊天更常用短语音；设置页重新整理；林离错过饭点会补吃、补觉后能恢复精神。详见 [2.0.9 更新说明](docs/releases/v2.0.9.md)。

- 你没有要求图片或语音时，林离按内容自己决定用语音还是文字：问候、闲聊、安慰、晚安多用一两句短语音，讲解、步骤、数字等用文字。
- QQ 回复时最近聊天记录可以连续复用，回复更稳定。
- 设置页改为“林离怎么回复 / QQ·微信 / 信件与记忆 / 更新与帮助”四个分组，开关即时生效；右上角合并为一个“账户”按钮并显示余额。
- 去掉不再需要的本地组件、云服务登录与“大模型”配置页。
- 错过饭点后，下课、精力恢复或新的聊天会让她补吃一顿；补觉后精力恢复会跨天保留，不再长时间停在休息。

## 2.0.8 - 2026-09-30

大幅减少 QQ 回复偶发发送失败（`PERSONAL_CHAT_DECISION_INVALID`），要语音时一定用语音回复。详见 [2.0.8 更新说明](docs/releases/v2.0.8.md)。

- QQ 回复的固定规则放进可缓存的开头部分，每轮按全价计费的输入更少；输出格式也更稳定。
- 模型把回复包在单项数组里时照常发送，不再判为失败。
- 本轮已决定发语音时，林离直接用语音说话，不再说“不想发”“等下再发”。
- QQ 设置页：连接 Key 后，之前“读不到 Key”的旧报错自动消失；其他报错注明是哪一时刻的失败。

## 2.0.7 - 2026-09-29

修复 QQ 回复因附带的提醒或偏好设置不合规而整条发送失败（`PERSONAL_CHAT_DECISION_INVALID`）。详见 [2.0.7 更新说明](docs/releases/v2.0.7.md)。

- 缺少你原话依据的偏好变化、超出七天的时间等，现在只忽略这一项设置，回复照常发出，并在诊断中记录原因。
- 你明确约好的联系时间（如清晨叫醒）任何时刻都会安排，不受林离作息限制；她自己发起的联系仍只在 8:30–24:00。
- 回信生成失败时诊断记录具体原因。
- 回信开头不再出现 `[[image:...]]` 这类插画选择标记。
- QQ 质量检查偶发超时只重检一次，不再整条重写并重复扣费；QQ 设置页对缺少 Key、余额不足给出明确提示。
- 林离的情绪扩展为 19 类（喜怒哀惧与亲近），当前心情带强弱。
- 世界页标题直接说她在做什么，心情和原因用自然说法，去掉系统术语。
- 深夜聊天时林离不再说自己“还没醒”，也不借作息打发你。
- QQ 回复先理清谁在做什么，不再把林离自己说要做的事安到你身上。
- 林离每天生成一份当天的安排候选（活动、饭菜、经过），参考最近七天避免重复，日常不再千篇一律。

## 2.0.6 - 2026-09-29

修复林离回信变得冷淡、带攻击性，以及 Key 带空格时回复失败。详见 [2.0.6 更新说明](docs/releases/v2.0.6.md)。

- 林离的心情不再凭“此前的心情仍在延续”一直保持烦躁；过期的心情不再影响回信。
- 回信可以带情绪，但不迁怒、嘲讽、贬低或攻击你。
- 信里表达想听林离的声音时按语音要求回信；媒体要求改为按语义判断。
- 能正确核对 JEV 判断的最低收费 0.01 元；结算失败时记录具体原因。
- 导入或保存时带有首尾空格、换行的 Olivia 账户 Key 不再导致 `JEV_BILLING_ACCOUNT_UNAVAILABLE`。

## 2.0.5 - 2026-09-29

减少林离日常在后台的无意义更新和扣费。详见 [2.0.5 更新说明](docs/releases/v2.0.5.md)。

## 2.0.3 - 2026-09-29

修复回忆失效导致的编造，记住双方称呼，降低每封回信的判断成本。详见 [2.0.3 更新说明](docs/releases/v2.0.3.md)。

- 回忆不可用时明确要求不编造往事。

## 2.0.0 - 2026-09-29

汇总自 1.3.14 以来的改动。详见 [2.0.0 更新说明](docs/releases/v2.0.0.md)。

- **JEV 判断链路**：回复意图、媒体形式、人格信息选择、记忆检索与核验、世界更新、情绪、主动联系和回复复核统一由云端 JEV 判断；判断异常明确记录，不悄悄回退到旧的小模型。
- **世界与聊天、信件联动**：回复后单独判断是否需要更新世界，区分打算、进行中、已完成和取消；回复使用对应时刻的世界证据。
- **生活事件与用餐**：世界事件补充过程、结果、角色感受与后续打算；三餐分别记录状态和时间，今日安排按时间排列课程与用餐。
- **情绪、关系与角色变化**：持续情绪综合交流、世界经历、身体状态和作息；兴趣与偏好变化需要经历支持。
- **记忆一致性**：保留原话、说话人、时间和来源，处理后续更正与跨轮指代。
- **信件、QQ 与启动体验**：随信照片藏在信纸下露出一角，语音工具栏移到信纸外；QQ 图片发送确认独立等待 120 秒；新开机动画播完停在末帧，等主界面就绪再退出。
- **只需一个 Olivia 账户 Key**：移除 DeepSeek、OpenCode Go、阿里云百炼等自填大模型接口和自填 GPU 服务地址，升级后旧配置被忽略。
- 实时对话（Live）暂不提供，以后再做。
