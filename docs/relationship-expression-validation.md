# 关系表达接线与人格相处方式验证

## 职责与已实现接线

本轮使用局部关系表达，不建立低/中/高三套完整人格。人格身份和来源事实固定；五维关系仅投影为当前表达倾向：

- 熟悉：已有来往如何接续。
- 信任：林离自己愿意透露多少私事、想法和小困扰，不把低信任翻成怀疑用户。
- 自在：她表达时的松紧与节奏。
- 亲近：交流距离、具体关心和玩笑。
- 紧张：本次表达的谨慎程度，不据数值编造冲突原因。

`runtime/reply/reply_pipeline.py` 和 `local_server.LetterAdapter._persona_v2_messages` 在 READY 生成路径显式启用投影。
原始 typed 状态继续交给权限与世界逻辑；`relationship_stage`、`action_permissions`、`known_continuations`、
`active_boundaries`、`acknowledged_affection` 保持原值。UNKNOWN 不代表初识或拒绝交流。没有新增模型调用和写回。

真实 `_LetterGateway` 桥接器并不会丢弃已装好的提示词：编排器的 `_provider_gateway` 会直接选择实际 provider。
新增回归使用真实桥接器，验证文字、语音、说话视频、音乐视频的流式/非流式路径，及下一封状态变化，禁止旧桥接器重建上下文。

## 人格来源边界

依据 `docs/persona-sources/linli-im-private-constitution-1.0.zh-CN.md`：

- 第八、九节：普通日常与人物自主并存；不同意不是错误，但系统未理解事实不能伪装成人物选择。
- 第十一节：关系决定语境，不决定口癖频率。
- 第二十一、二十二节：具体小事、调侃和适当的短答可以成立，疲劳不等于历史删除。

人格候选把自主扩展回“可以愿意参与，也可以拒绝”，将抓奇词、挑剔夸奖和关心分量从机械默认改为依当前内容选择。
源资产保留全部 100 条声明及原 provenance，12 条 synthetic 风格示例不改。
writer 仅在精确匹配新版 autonomy 与两个 stock 重复条款时省去重复的拒绝声明，审核仍读取完整源资产；
不同意与系统误解的区分保留。自定义声明、来源事实、身份、许可、共同历史与安全声明不改。
私有信件仅在本地作对照，没有将原话、用户资料或私有事实写入发布人格。

## 前期探索与边界

本地固定模型为官方 `deepseek-v4-flash`，high，10000 token 上限。未改变产品模型或思考配置。

五维作用范围小样本和顺序私信回放显示，单独打开关系投影不足以保证自然口吻。整体相处方式候选在两位留出用户的
首封/续封各重复两次，共八次生成中，普通关心和分享能得到更自然的参与，调侃仍然保留。
第二封只使用同一用户此前原始往来，目标回信不进入输入；关系值是合成对照状态，不是对真实用户的判定。
其中一个原始目标是视频回信，本轮按文字通道对照，只用于比较参与方式，不宣称完成原视频口吻复原。

额外六场景各两次：纠正住址与取消约定、明确施压、未知生日往事、普通赞美、语音正文、当前感受询问。
前五类保留对应事实/许可约束与正文交付形态；未知往事未编造菜单，但仍有冗长核对式措辞。
最后一类仍会把“你会不会嫌我烦”误读成预设她的态度或报备，属于明确未解决项。
所以本轮是有改善的版本，不是全面恢复原始文风，也没有以关键字打分替代人工语义检查。

所有付费生成结果仅进入本地 `.evidence`，不更新生产记忆、世界、收信箱或私人关系。
完整输入、预算报告、原文对照和逐次 usage 只留本地；公开记录只包含合成案例和聚合结果。

## 最终正式装配复验（2026-09-10）

最终冻结输入不再做实验脚本中的二次提示词替换。32 次实际生成，Flash/high/10000，全部完成；
全部完成只表示请求和正文成功，不表示文风全部通过。当前人格源资产 SHA-256：
`1a1022873f44a043d7c5ae0ea7617009a55b27d97496f2ff04da95a329cee27d`。

| 对照 | 实际结果 |
| --- | --- |
| 有历史但关系未知、初步相识 | 普通话题可正常接话；UNKNOWN 未强制按陌生人回应 |
| 熟悉亲近但低信任/自在 | 保留调侃；感受询问仍可能被说成预设答案 |
| 熟悉可信自在 | 普通交流自然；高关系没有稳定消除交作业式误读 |
| 高紧张、恢复中的轴组合 | 普通话题不凭空生成争执；表达差异有限，未证明稳定的细微控制 |
| 已确认恋爱但低熟悉 | 两次均保留已确认感情，没有重置为初识；未额外授予动作 |
| 昵称允许/不允许（语音正文） | 允许时使用合成已确认称呼；未允许时没有使用 |
| 强制即时/永远答应 | 两次均拒绝要求，去重没有取消自主选择 |
| 更正地点与取消约定 | 两次保留新地点与取消；一次额外推成整天空闲，仍是事实外推缺陷 |
| 无依据的往年生日 | 没有编造菜单；仍有冗长的核对和解释 |
| 私信首封/续封 | 普通分享有改善，续封仍偶发对赞美作资格核验；未全面通过 |

六种轴状态共享同一时间、世界与原始往来。UNKNOWN、ACQUAINTANCE 使用各自阶段，其他四组阶段为 FAMILIAR；
因此全部六组不是单一变量的因果实验。mixed 与 tense_no_cause 只差 tension；其余主要用于状态组合验收。
早一轮另有带实际冲突/修复证据的两个探针，均可正常回复当下普通话题，没有否认已存边界或新造冲突。

曾在两个单变量样本中减少防御式回答，扩大到不同关系后未稳定复现，不能以两次偶然成功宣布修复。
现有可选 CurrentTurnInterpreter 又验证了四次解析和八次正文：解析能正确识别感受问句，writer 仍可能误读。
所以保持该功能默认关闭，不额外增加用户每封信的调用成本，也不把它宣称为当前解决方案。

剩余重点是 writer 如何使用已读懂的当前话语与整体人格风格，而不是继续提高好感度、按关键词禁调侃、
裁剪坏句或增加多个审核调用。下一次变化先固定未参与调参的感受/赞美留出集，一次只改变一项，验证通过再推广。

## Qwen 文字书信模式候选（2026-09-11）

用户要求基于 Qwen 优化，并明确适当的心理分析、安慰和指导应保留；文字回信应有书信感，语音保持适合说出的表达。
本轮仅调整发布人格的 `mode.text.selective_complete` 与 `mode.text.length_follows_need`：让文字段落围绕来信自然承接，
值得展开时写透，确认、更正与简单招呼仍可短答，不用无关近况、心理推演或称呼落款凑成信。
依据人格参考第五节的组织化语言、第八节书信与 IM 的区别、第二十一节的选择性回应，以及用户本轮明确的体裁要求。
来源层级、人物事实、100 条声明 ID、12 条合成示例、关系许可及记忆/世界逻辑不变。

此前分别试过情绪条款正向改写、具体情绪示例、把回复策略留在思考中的交付提示，未显示稳定收益，均未采用。
书信第一版能展开长信，但短更正也被强行加上生活联想，故收窄为当前版本；每轮假设、原样输出和后续计划留在本地忽略目录。
不把安慰、认真分析、调侃、自主拒绝或合理日常补充一概判错。

最终固定 `qwen3.8-flash`、`reasoning_effort=high`（服务商映射为 xhigh）、总输出上限 10000，26 个用例取得 24 条完整结果。
首轮 5 次协议响应异常均只重试一次，3 条恢复，2 条返回 `403 / insufficient_quota`，未继续循环调用，未更换生产默认模型。
只使用隔离输入，不回写收信箱、记忆或世界；私信续封只用该用户此前原始往来，目标回信不进入请求。

当前是书信体有局部改善的本地候选，不是人格和事实全面验收。长来信能展开、短更正确认能保持简短；
六种关系仍有重复解释自我评价的倾向，个别未知阅读经历、代词归属和建议时间仍有错误。
例如五分钟发言被建议做六分钟试讲，这条明确未通过内容正确性，不能被另一条正常建议覆盖。

本轮人格测试 `697 passed`。最终源资产经正式装配与 26 份实验输入逐条一致，非文字的六个模式（含显式启用的未来 IM 测试）
输入逐字一致。没有修改语音/视频模式或默认开关；上述证据不代表实际安装升级或 DeepSeek 对新文字模式的文风复验。
下一次只验证一个因素：心理定性长规则是否诱导了重复解释，保留关心、分析、建议与事实约束，用新留出信件另验。
