# Olivia 1.1.6 · 主动来信

- 新增主动文字信和语音信，复用原生信箱与只读信纸。用户仍从普通写信入口回信。
- 主动来信默认关闭。在设置中开启“允许主动写信”；需要后台检查时，再开启“登录 Windows 后在后台检查主动来信”并保存。
- 登录后台只准备待写意图，不调用模型、不提前生成信件。打开应用后重新核实上下文，符合条件才生成；长期离线不会积攒补发。
- 滚动 24 小时最多三封，有未读主动信时暂停后续投递。生成期间暂时锁住发送，草稿保留，旧信仍可查看。语音失败时交付文字。
- 主动信按林离单方发言保存完整正文和来源；不伪造用户来信，不凭单方表达增加关系事实或修改用户作息。记忆、世界与媒体交付沿用可恢复、去重的写入链路。
- 补齐旧版本登录启动器迁移与后台卸载清理。升级不会自动开启登录启动。

仅发布 `.oliviapatch` 和两份校验文件，无需重新下载模型或完整安装器。在“补丁更新”中导入补丁并填写本页提供的 Manifest SHA-256，完成后完全退出并重新打开 Olivia，再到设置中按需开启功能。

验证覆盖后台机会、配额与重启、单方记忆、语音成功/失败、发送互斥、原生界面投影和升级恢复；原版资源隔离副本的补丁与 JavaScript 语法检查通过。自动测试不等于真实模型文风或语音试听验收，本次未调用用户的真实 API、未改动用户记忆。
