# Olivia 0.1.460

本版合并视频语音、寄信与等待界面、自定义模型配置、记忆，以及人格任务收尾候选 42 的成果。

## 安装与升级

已安装用户下载 `olivia-local-backend-0.1.460.oliviapatch`，在本地陪伴的补丁更新中安装，再完全退出并重新启动 Olivia。新用户使用同页的 `Olivia-Setup-x64.exe`。两种方式使用同一份发布源码。现有模型与离线包可以继续使用，无需因本次代码升级重新下载。

## 改进

- TTS 根据正文逐句编排语调和语速，保留音色参考；取消为压到 50 秒而自动加速，动作视频按自然语音时长适配。
- 改进 TTS 进度、资源释放和内容校验；视频生成中继续使用原版等待界面，显示正在录制视频，避免提前呈现文字完成状态。
- 自定义模型接口允许空 key，测试、保存、重启和记忆接入均支持不发送 Authorization；预设云服务仍按原有要求使用 key。
- 改进寄信等待与失败恢复、启动恢复及视频安装诊断。
- 长期记忆按对应交流日期写入，写入期间的状态检查避免争抢操作；官方 Flash 记忆提取使用有界 max 思考配置，可能增加提取延迟与 token 用量。
- 合入人格候选 42 的人格资产、上下文装配、交流归属、日常生活与关系状态处理及审核改进。当前来信解释步骤随包提供，保持默认关闭；仅显式设置 `OLIVIA_LETTER_CURRENT_TURN_INTERPRETATION=1` 时开启，开启后增加一次模型调用。

## 验收和已知限制

视频前半段真实运行完成：TTS 用时约 234 秒，语音 51.76 秒，视频 51.84 秒，完整解码通过；语音 PCM 与用户认可的独立试听一致，用户听验通过。本轮没有重新运行音乐后半段。

人格成果属于收尾候选的阶段性改善：前三封真实时序回放完成，记忆和世界状态均提交；第四封中止，完整 79 封未验收。仍可能出现评判语气、编造习惯或事实，裁决到局部改写的原因信息传递仍有已知不足，不能将此版本理解为人格已完全恢复。

安装器不含原版游戏、模型权重、个人信件或密钥。提供 SHA-256 校验文件；本社区安装器未购买代码签名证书，Windows 可能显示未知发布者。
