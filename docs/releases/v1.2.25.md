# Olivia 1.2.25

本次补丁改善模型回复格式兼容、长期记忆读取，并增加曲库播放方式选项。

- 曲库新增“顺序播放”和“随机播放”，默认顺序播放；从曲库点歌后，自动切歌和上下首也按所选方式工作，跳过尚未下载的曲目。
- 根据模型能力选择工具调用、JSON Schema 或 JSON 输出，校验结果并进行有限的格式修复重试，减少不同模型在回信方式识别等结构化任务上的失败。
- 已截断的模型输出不再作为完整结果使用；兼容重试不会把格式错误的内容直接当作有效结果。
- 修复提取记忆包含换行、制表符时，长期记忆列表和搜索整体显示不可用的问题；区分返回数据格式异常与服务不可用。
- 记忆依赖导入失败时，寄信前明确提示并保留草稿，避免接受信件后长时间等待、最终只显示通用失败。
- 长期记忆组件校验增加实际导入和临时向量数据库检查，避免只有文件存在、实际不能加载的组件被判为正常；附带本地依赖排查脚本。

验证：上述改动联合回归 339 项通过；原生曲库脚本补丁通过语法及重复应用检查，浏览器验证播放方式选择与页面切换。本机嵌入式运行环境的 Mem0 和向量库导入通过。未进行真实模型账号和用户机器验收；诊断包中的向量库依赖导入故障尚未确定具体损坏依赖，本版不宣称已修复所有记忆不可用情况。

升级：下载本页更新 ZIP，在“本地陪伴 → 补丁更新 → 选择补丁并更新”中选择，无需解压。安装成功后关闭并重新打开 Olivia，无需重新下载完整包。需要时可在同一页面回滚上一版本。
