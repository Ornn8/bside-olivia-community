# BSide Olivia v0.1.0

这是面向 Windows 10/11 x64 的首个社区预览版。普通用户只需下载 `Olivia-Setup-x64.exe`；安装器会创建隔离副本，不修改正版 Steam 目录。

## 已验证能力

- 安装器内置并校验 Python 3.12.10、本地 HTTP 核心依赖及 SHA-256，不在安装过程中临时下载核心运行时。
- 登录后的初始设置可保存 OpenAI-compatible LLM 地址、模型和 API key；密钥使用 Windows 当前用户 DPAPI 保存。
- 可选模型和媒体 provider 按需安装，后续可在原版客户端 Settings 的“本地陪伴”页面管理。
- 桌面和开始菜单快捷方式直接启动 Olivia 本地版。
- Settings 支持选择维护者发布的 `.oliviapatch` 更新包，并可回滚到上一活动版本，无需重新安装完整客户端。

当前社区预览安装器未进行 Authenticode 数字签名，Windows 可能显示“未知发布者”安全提示。请只从项目 GitHub Release 下载，并使用同页 `.sha256` 文件核对安装器 SHA-256。

## 需要用户准备

- 合法取得的原版 Olivia 客户端 `0.0.9.627`。
- DeepSeek API key，或兼容 OpenAI API 的其他服务凭据。
- 只有启用视频回信、TTS、口型或音乐时，才需要按客户端提示准备对应模型、运行时、显存和磁盘空间。

## 已知限制

- 视频回信自动管线的阶段路由和短时 provider 调用已经验证；完整成片的跨设备视听效果仍需继续积累人工验收。
- Mem0、CosyVoice、LatentSync、音乐生成与分离模型不包含在核心安装器中；缺失时会明确显示不可用，不会伪造成功。
- 当前未购买代码签名证书，因此 Windows 会把安装器显示为未知发布者；SHA-256 只能帮助核对下载文件，不能把安装器变成受信任发布者。
- Live 实时对话仍暂停，不属于本版本能力。

## 升级与回滚

日常升级无需重装：从项目 GitHub Release 手动下载 `.oliviapatch` 和对应 Manifest SHA-256，在原版客户端 Settings 的“补丁更新”中选择文件并安装，随后重启 Olivia。出现问题时可在同一页面回滚到上一版本。

若需要完全移除本地版，请运行安装目录中的 `UNINSTALL.cmd`。它只删除补丁拥有的程序文件，保留用户数据；正版 Steam 目录不会被修改。
