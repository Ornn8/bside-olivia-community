# Olivia 1.1.0

安装器、程序运行版本和升级补丁统一为 **1.1.0**。本版包含此前 2250.10 的全部改进：写信与翻唱共用原生窗口、世界独立主页面、折叠布局，以及记忆召回和媒体完成记录修复。

## 下载哪个文件

- **首次安装**：下载 `Olivia-1.1.0-Setup-x64.exe`，运行后选择正版 Steam 游戏目录。安装器包含本地核心运行环境；语音、翻唱、口型等组件继续按需导入已有离线包。
- **已经安装 Olivia**：下载 `Olivia-1.1.0.oliviapatch`，在设置的补丁更新中导入，完成后重新打开程序。无需重新安装客户端或下载模型。
- `.sha256` 是校验文件，不是需要安装的组件。

**FFmpeg 无需重复安装。** 新安装器已包含 FFmpeg。此前发布中的 `Olivia-tools-20260909.zip` 是 FFmpeg 媒体工具的独立离线补装包，用于音视频转换和本地演奏导入。已安装过相应依赖的用户继续复用；它不是新增模型，也不是本次升级的必装项。本版不重复附带它，工具包仍在既有新管线离线组件中。

修复安装器增加 FFmpeg 依赖后，仍按旧依赖数量校验，导致 `OFFLINE_CORE_MANIFEST_INVALID` 的问题。校验数量现在跟随固定依赖清单，逐文件哈希验证保持启用。

## 版本与数据

旧版长版本号仅保留在历史发行和兼容记录中；1.1.0 起新安装和补丁升级都显示一致的程序版本。原版游戏资源版本属于兼容校验标识，保持不变。升级保留信件、记忆和已有离线组件。

## 验证边界

此前完整翻唱已通过独立信箱生成，约 4 分 28 秒。本次仅统一发行版本及新安装版本显示，不修改生成模型。媒体完成记录覆盖合成渲染器、真实存储和检索回归，尚未完成长期 Mem0／世界实际提取写回验收。历史媒体不会仅凭完成状态自动回填。
