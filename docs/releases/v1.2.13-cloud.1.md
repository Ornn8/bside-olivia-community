# 1.2.13+cloud.1 本地候选版

基于社区 1.2.13。设置页新增“媒体生成服务”：选择本机或云端 GPU，填写 HTTPS 服务地址和 API Key，测试连接、保存或清除。客户端没有默认云端实例地址；更换实例只需更改配置。更换地址时必须提供对应 Key，不复用原地址的密钥。

API Key 使用 Windows 当前用户 DPAPI 加密保存，状态接口不回显。保存后对后续生成任务生效，重启后恢复。云端任务通过独立 API Key 提交、轮询、下载；账号管理服务不转发生成请求。云端出错不会静默回退本机。聊天模型设置、记忆与关系仍保留本地，媒体生成所需文字和素材发送至用户指定的 GPU 服务。

云端已有共用场景按内容哈希匹配。客户端仍需 FFmpeg 与相关共用视频素材用于校验、匹配及组合媒体；不再要求本机安装生成模型。语音、视频、歌曲与翻唱能力以目标服务返回的可用列表为准。

包含已验收的长语音上下文规划修复。此包用于本地验收，尚未发布为社区正式更新。
