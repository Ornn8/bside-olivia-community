# Olivia 1.2.14

本版重点调整林离的主动联系行为：关系不再只影响回复语气，也会影响她为什么主动、主动到什么程度，以及面对沉默时如何克制和恢复联系。

- **关系驱动主动行为**：基于已有熟悉、信任、自在、亲近、关系阶段与紧张状态，派生 `reserved / familiar / trusted / close / committed` 五档主动行为画像；不新增独立好感分，也不改变原有关系事实。
- **QQ／微信主动消息更像真人**：浅关系仍需要明确理由；熟悉后可以延续共同兴趣和旧话题；朋友与信赖关系可以分享小事、状态和轻量关心；亲近关系允许低信息量日常、随手分享、想念和没正事也想说两句。关系紧张时自动提高克制程度。
- **沉默不再永久锁死主动联系**：此前连续两条主动消息未回复后会一直停止主动，直到用户再次发言。现在改为“先怕打扰、后随时间衰减”，并参考双方最近真实交流节奏；关系越深，重新自然开口的门槛越低，但不会连续催回复。
- **主动内容边界增强**：区分双方自然结束后的安静与林离已经发过消息但用户未回复。允许亲近关系表达想念、期待和轻微失落，但禁止把这些情绪写成责备、控制、在线监控或重复催促；第二条主动消息需要新的理由或新的时间背景。
- **主动来信共享同一关系画像**：信箱仍比即时聊天克制，但跟进延迟、每日主动来信预算和长时间沉默后的联系机会会随关系变化。亲近不等于无意义地频繁写信，正式来信仍需要适合信件渠道的内容。
- **关系变化立即重新校准节奏**：一次有效互动刚让关系进入更亲近阶段时，下一次主动检查会按新的关系画像重新安排，不继续沿用旧阶段过长的等待时间。
- **联系方式邀约门槛修正**：仍要求熟悉／信任／自在／亲近中至少三项达到较高水平，但达到门槛后只需一次已落盘、有证据的有效互动即可进入邀约资格，不再额外要求第二次隐藏的资格确认。
- **兼容旧数据**：旧存档没有主动行为画像字段时会从已有关系证据保守恢复，不需要清空关系、记忆、历史信件或重新导入数据。

## 更新方式

下载 **Olivia-1.2.14.zip**，在“本地陪伴 → 补丁更新”中选择该 ZIP。安装完成后完全退出并重新打开 Olivia，确认当前运行版本为 **1.2.14**。也可使用同页 `.oliviapatch`。

本次是**本地版**发布。云服务版本继续作为独立分支维护，本补丁不包含独立 cloud 分支上的云 GPU／云组件改动。

## 验证与限制

发布前回归覆盖完整 pytest、仓库 hardening、whitespace 检查和 Windows 离线安装器构建。主动行为仍然保留用户明确暂停、睡眠时段、未完成请求、主动发送预算和渠道可用性等安全边界。

主动联系最终正文仍由模型结合真实关系、最近连续聊天、记忆和当前上下文生成，因此“更自然”不等于固定次数保证；没有合适动机时模型仍可选择不打扰。发布包不包含私人信件、聊天记录、诊断包、实验输出或密钥。
