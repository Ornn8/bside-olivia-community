# Resonance Edition 1.1.19

- 修复部分新回信类型在信箱列表中缺少图标的问题。新图标与原版共用图标注册、渲染和状态切换机制，兼容旧补丁，保留原有图案与配色。
- 修复“你是什么学校毕业的”等直接问句没有带入已有学校设定的问题，同时保留用户与第三人信息的归属判断。
- 调整昵称授权的回信投影：区分已有授权记录、双方称呼方向与本次接受意愿。没有历史授权不再等同于必须拒绝新称呼；已有拒绝边界和亲密权限保持有效。
- 新增昵称投影字段的内部信息泄露拦截，避免它出现在回信正文中。

已有用户下载 `Olivia-1.1.19.oliviapatch`，在补丁更新中使用同页 `.manifest.sha256` 文件里的校验值。更新后完全退出并重新打开程序。首次安装使用 `Olivia-Setup-x64.exe`。

本次未更改人设资产、离线模型或音乐组件，已有离线包可继续使用。昵称修复已验证输入编排与隔离接线，尚未进行新的真实模型效果验收；不同模型的表达仍可能不同。尚未定位的记忆导入失败不属于本次修复。
