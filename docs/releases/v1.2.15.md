# Olivia 1.2.15

本次修复导入官方历史信件后，相关原文在实际回信链路中可能没有被最终生成模型读取的问题。

- 修复历史原文经过回复前核对后被移除的问题。核对结果现在作为辅助信息保留，已经选入上下文的双方原文继续进入最终回信。
- 修复首次导入历史信件后，记忆后台仍持有旧的不可用 Archive 句柄、导致原文索引补建没有及时接上新导入数据的问题；无需重新导入历史信件。
- 修复部分旧 Archive 时间戳以字符串保存时无法被精确来源读取的问题。
- 改进“上面是什么”“之前那件事”等省略式追问：可利用已经送达的近期用户原话补全检索线索；没有足够线索时不会随机认领一段旧历史。
- “好久不见”“上一封信”等场景可读取一个严格受限的旧通信窗口，并继续区分旧通信与当前状态；未知日期不会被伪装成最近发生。
- 保留世界事件中的明确 source_id 原文追溯能力，避免防误召回逻辑误伤已有世界证据链。
- 新增隐私安全的历史召回诊断，只记录数量、状态和不可逆来源标识，不保存用户原文、查询、Prompt、路径或账号 ID。

## 更新方式

下载 **Olivia-1.2.15.zip**，在“本地陪伴 → 补丁更新”中选择该 ZIP。安装完成后完全退出 Olivia 并重新打开，确认当前运行版本为 **1.2.15**。也可以直接选择同版本 `.oliviapatch` 文件。

不需要清空记忆，也不需要重新导入官方历史信件。已经存在的 Archive 会由现有后台索引机制继续补建缺失索引。

## 验证

Windows / Python 3.12 完整回归 **4049 项通过，8 项跳过，1 项 deselected**；repository hardening、whitespace 与 Windows 离线安装器构建通过。新增回归覆盖官方导入、重复导入、SQLite Archive/原文索引补建、重启读取、最终 ReplyPipeline 输入、模糊历史指代、遗忘来源与多渠道回复链路。

本版不宣称消除所有记忆召回或模型理解错误；没有足够历史线索时，林离仍应保持不确定或自然询问，而不是猜测过去发生了什么。
