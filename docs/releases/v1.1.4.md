# Olivia 1.1.4 — 更新补丁

- 修复保存大模型配置后，长期记忆可能仍读取启动时旧 key 变量的问题。地址、模型与 key 现在同步交给记忆模块。
- 优化启动时读取离线组件清单：避免逐条访问数万个非入口文件路径，安装时仍保留完整文件校验。隔离测试中，3.65 万条清单读取由约 20 秒降至约 0.85 秒；这不是完整启动耗时。
- 新配置默认模型改为 `deepseek-v4-pro`，已有用户保存的模型选择保留。
- 包含已合入主线的关系边界建立/撤销接线，以及当前生活与作息上下文的裁剪优先级修复。

本次仅提供 `Olivia-1.1.4.oliviapatch`。在“补丁更新”中导入后，完全退出并重新打开 Olivia。无需重下离线模型。首次安装请先使用 1.1.3 安装器，再导入本补丁。

验证：相关测试 165 项通过、1 项跳过；记忆配置回归 51 项通过。未重新生成音视频。尚未确认修复用户报告的退出后 GPU 占用，也未确定异常 API 费用来源。
