# BSide Olivia v0.1.2

这是 2026-08-28 发布的 Windows 10/11 x64 社区预览版更新。对应的 [GitHub Release](https://github.com/Ornn8/bside-olivia-community/releases/tag/v0.1.2) 为 Pre-release，建议先小范围试用。

公开 tag 与 Release 从 v0.1.0 直接到 v0.1.2，当前没有公开的 v0.1.1 tag 或 Release。v0.1.2 发布说明把已安装的 v0.1.1 列为可升级来源，因此本文件只把它视为中间安装版本，不补造 v0.1.1 发布记录。

## 新安装

从 GitHub Release 下载：

- `Olivia-Setup-x64.exe`
- `Olivia-Setup-x64.exe.sha256`

核对 SHA-256 后运行安装器。当前安装器未做 Authenticode 商业签名，Windows 可能显示“未知发布者”或安全警告。

## 从 v0.1.0 或中间安装版本升级

下载：

- `Olivia-v0.1.2-local_backend.oliviapatch`
- `Olivia-v0.1.2-manifest-sha256.txt`
- `Olivia-v0.1.2-package-sha256.txt`

在 Olivia 的“设置 → 本地陪伴 → 补丁更新”中选择 `.oliviapatch`，粘贴 Manifest SHA-256，安装后关闭并重新打开 Olivia。补丁失败时不会覆盖当前活动版本；需要恢复时，可在同一页面回滚到上一版本。

## 本次修复

- 恢复写信入口，并修复设置、初始设置及关闭交互被遮挡的问题。
- DeepSeek 官方与 OpenCode Go 请求使用稳定客户端标识，连接测试与真实推理保持一致。
- 组件补丁从活动版本目录启动，不再继续运行旧后端。
- 首次升级只在确认监听进程属于当前安装自带 runtime 后迁移旧服务，不同安装实例不会互相复用后端。
- 客户端退出时回收其启动的本地后端，后续补丁和回滚无需重新安装整套客户端。

## 验证边界

PR #207 的两项 Windows public-smoke 与离线安装器构建通过；单机已安装副本完成了从中间安装版本到 v0.1.2 的升级，并验证旧后端迁移、版本化后端启动、客户端打开、设置页交互及 DeepSeek 官方连接测试。

这些结果不等于所有 Windows 机器都已验证。安装器未做 Authenticode 签名，完整视频成片的跨设备视听效果也不在本版本的自动化验证范围内。
