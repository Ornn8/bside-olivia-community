# Olivia 1.1.1

修复安装阶段错误提示丢失的问题，便于定位部分用户遇到的 `SETUP_INSTALL_FAILED`。

- 文件被占用、访问被拒绝、磁盘空间不足和文件缺失，现在分别显示对应提示。
- 未预期的 Python 异常记录错误类型、系统错误编号和程序内调用位置，不记录用户目录、异常原文或信件内容。
- 安装结果使用与 Windows 输出编码无关的 JSON，避免目录中的特殊字符导致结果输出失败。

**安装 1.1.0 失败的用户**：运行 `Olivia-1.1.1-Setup-x64.exe`，先关闭旧版 Olivia，保留原有信件、记忆及组件目录。若仍失败，请提供最新安装日志；本版增强诊断，不代表已确定每位用户失败的根因。

已正常使用 1.1.0 的用户无需重新安装。首次安装器继续内置 FFmpeg，已有离线模型继续复用。
