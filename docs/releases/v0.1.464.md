# Olivia 0.1.464

## 本地演奏与曲库

支持将已有本地演奏素材导入曲库，识别 `midi_*` 演奏目录及曲名清单；接入原生播放缓存、音频播放和演奏壁纸链路。修复导入入口重叠、曲目未登记、播放缓存未就绪及原生下载成功返回值兼容问题。相关导入设计署名：芙桃。

这里的 MIDI 目录导入是恢复已有演奏素材，不是将任意 MIDI 生成手部动作。S2C、PianoMotion10M 与 Blender 手部实验不包含在本版本中。

## 安装诊断

视频安装失败时记录阶段、清单文件标识、实际尝试来源，以及脱敏后的 HTTP、系统错误码和错误分类；失败状态保留当前文件。修复上一份文件复用本地缓存后，下一份下载失败仍显示 local 的误导。

诊断包保留这些信息，界面显示网络、超时、磁盘空间、权限、文件占用、路径过长等原因。记忆初始化增加 Windows 文件占用、路径过长、文件缺失及磁盘空间分类。不会导出异常正文、密钥、下载 URL 或用户绝对路径。

此前诊断包中的笼统错误无法追溯还原。更新后再次失败时，请立即导出新诊断包；诊断增强不代表所有安装根因都已修复。

## 验证与更新

本地演奏链路此前已在维护者设备验收。本次安装与诊断定向回归 231 passed、1 skipped；新增分类使用合成失败场景验证，尚未在反馈问题的用户设备复测。

已有安装可使用 `.oliviapatch` 更新；新用户使用 Windows 安装器。请保留已有离线包和用户数据。安装器未做 Authenticode 签名，可能显示未知发布者；随包提供 SHA256 校验文件。
