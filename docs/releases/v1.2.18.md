# Olivia 1.2.18

本次补丁修复 1.2.17 新增的 QQ / 微信绑定面板在原版客户端中显示 `Failed to fetch`、无法读取绑定状态的问题。

- 修复 QQ / 微信设置接口的跨域预检。原版客户端携带 `X-Olivia-Companion-Action` 请求头访问本地服务时，现在会对已信任的 Olivia 前端 Origin 正确返回 CORS 响应。
- 修复接口被原版客户端 catch-all 路由遮挡的问题。QQ / 微信设置请求现在通过限定路径的本地中间层处理，即使通用回退路由先注册，也能到达绑定接口。
- 继续沿用现有 Origin 白名单；未知外部网页不能调用这些绑定接口。
- 继续要求显式的本地确认请求头，并且只有用户已经在联系方式邀约中明确选择对应渠道后，才允许开始微信扫码或 QQ 配置。
- 微信二维码、验证码、轮询标识和登录凭据的保护方式不变；QQ Token 仍只以 Windows DPAPI 加密形式保存，不写入明文配置。
- 不改变 NapCat / OneBot、微信登录协议、关系资格或联系方式邀约逻辑。

## 更新方式

下载 **Olivia-1.2.18.zip**，在“本地陪伴 → 补丁更新”中选择该 ZIP；也可以使用同版本 `.oliviapatch`。更新完成后完全退出 Olivia 并重新打开，确认运行版本为 **1.2.18**。

如果此前已经收到联系方式邀约并回复了“微信”“QQ”或“两者都要”，不需要重新触发邀约；修复后设置页应直接显示相应渠道的绑定入口。

## 验证

修复新增了原版客户端形式的 CORS 预检与状态读取回归、外部 Origin 拒绝回归，以及“catch-all 已先注册”情况下的接口可达性回归。修复 PR 同时通过 Windows / Python 3.12 全量 `public-smoke`、仓库 hardening、whitespace 检查和 Windows 离线安装器构建。

云服务版本仍独立维护，本补丁仅更新本地版本。
