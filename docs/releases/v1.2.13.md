# Olivia 1.2.13

本次汇总此前暂停发布后的记忆召回、共享回复上下文、人设边界与联系方式邀约改动。

- **全回复链路同步**：书信、主动信、QQ／微信聊天、语音、视频及原创歌词共用人设、记忆、关系和世界状态。各渠道仅添加表达形式和交付要求；音视频转换不额外推进一次关系。
- **原文召回增强**：结合关键词与语义候选补充来源，保留双方原文、时间、来源和相关上下文，减少同一封信只召回一方、多个话题互相挤占的问题。实际生成入口不再沿用旧的 2400 字记忆限制。
- **回复前核对情境**：有历史证据时核对说话人、计划与已发生事件、时间范围及来源分歧。引用核验失败按话题降级，避免一个不可靠引用牵连其他已确认内容；读取失败与“没有记录”分开处理。
- **当前世界状态接入**：区分近期交流、历史原文、提取记忆和当前生活活动，避免把旧习惯、旧计划直接当作现在。保留暂停记忆、遗忘、用户隔离及当前信件排除规则。
- **记忆读取与历史导入修复**：增强读取异常与来源追溯的处理，保留成对原文；无时间戳的导入不再伪装成当前交流时间。
- **共享人设边界**：专业名词和课程分享不自动触发通用助手式讲解；被指出说话不对时先核对具体内容，不通过指责用户、猜测动机或编造经历来圆场。规则在各回复渠道共用。
- **联系方式邀约提速**：满足既有关系资格后，在下一轮主动检查时优先生成文字邀约，不再额外等半小时或被普通话题冷却、模型延期决定拖延。仍需开启主动写信、配置联系方式并满足可联系时段、未读和发送限额；已邀约或拒绝后不重复发送，失败重试有持久化上限。

## 更新方式

下载 **Olivia-1.2.13.zip**，在“本地陪伴 → 补丁更新”中选择该 ZIP。安装完成后完全退出并重新打开 Olivia，确认当前运行版本为 **1.2.13**。也可使用同页 `.oliviapatch`。无需清空记忆、重新导入信件或重下离线模型组件。

## 验证与限制

本地回归覆盖记忆、导入、关系、各回复模式、渠道状态及补丁安装。隔离环境使用 184 封信验证原文导入与检索，并使用真实模型检查部分书信、口播、跨日聊天和人设纠错场景；不等同于实际 QQ／微信投递或全部音视频体验验收。

**本版没有彻底解决幻觉。** 混合追问中仍观察到模型补充原文没有的生活细节，不能保证每次召回、理解和人设表现都正确。历史证据核对可能增加一次模型调用，完整原文也可能增加输入量和等待时间。发布包不包含私人信件、聊天记录、诊断包、实验输出或密钥。
