# Olivia 1.2.3 · Resonance Edition

本版新增 **AMD 本地语音实验支持**。尚未完成 AMD 实机生成和听感验收，请按实验功能使用并反馈诊断；不承诺所有 AMD 型号可用。

- AMD 用户可从原生「安装声音与视频组件」入口导入专用 `Olivia-voice-amd-1.2.3.zip`，无需先装 NVIDIA 语音包。专用包包含 ROCm/PyTorch 环境、Breeze INT8 hybrid 模型、参考音色及 2250 LoRA，导入过程不再下载依赖。
- 正式语音回信读取所选运行包，使用 ROCm 后端；修复已有 NVIDIA 环境配置可能覆盖 AMD 运行包的问题。组件列表会显示「AMD 实验」。
- AMD 使用保守的 eager 注意力和量化路径，可能比 NVIDIA 现有路径慢。需要 Windows 11 和官方 ROCm 7.2.1 兼容显卡/驱动，建议 12GB 以上显存。
- 诊断保留 AMD 后端标识和 HIP/ROCm 错误类别；另提供独立硬件诊断及语音测试工具，不自动上传，不采集私人信件或密钥。
- AMD 生成与独立测试工具使用 Python 隔离模式，避免读取用户目录中的其他 Python 依赖。旧版独立预览工具已撤回，请改用本版离线组件。
- 本次仅适配说话语音。翻唱、原创歌曲和口型视频仍使用原有 NVIDIA 运行环境。已有 NVIDIA 用户无需重新下载语音包，原有离线组件继续复用。

已有用户导入 1.2.3 补丁，新用户使用 1.2.3 安装器；AMD 专用语音模型包单独分发。独立测试包 `AMD-Voice-Preview-1-UserTest.zip` 不是应用组件包，不要导入设置页面。

验证边界：代码和模拟分支、组件导入与路径迁移、NVIDIA 对照可验证；AMD 驱动、实际速度和听感需要用户实机验收。此前用户语音包的长路径导入疑点不在本版修复范围内。
