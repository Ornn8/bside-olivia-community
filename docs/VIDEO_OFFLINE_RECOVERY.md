# 视频离线导入：补齐 Breeze 运行依赖

旧视频离线包缺少部分 Breeze Python 依赖，模型文件处理完成后仍会联网安装，导致满进度长时间等待。修复版将全部 38 个锁定依赖纳入视频清单；安装只读本地 wheel，不再查询 PyPI 或 PyTorch 索引。下载与离线导入均保留逐文件大小和 SHA-256 校验。

修复版同时跳过未变化的音乐脚本重装，避免状态查询反复扫描整个音乐目录；脚本发生变化时仍执行原有完整校验和事务更新。

## 已经下载旧 ZIP

1. 完全退出 Olivia，安装包含本修复的后端补丁，然后重新启动。
2. 将 `Olivia-breeze-runtime-offline.zip` 放在原视频 ZIP 的同一目录，保留这个补充包文件名。两份 ZIP 均不需要解压。
3. 在视频回信页面点击“导入离线包”，选择原视频 ZIP。程序只会从补充包读取清单中指定的 Breeze wheel，并校验哈希。不要单独选择补充包作为完整视频包。

无需删除已有模型或记忆数据。已通过校验的缓存会被复用。补丁本身不包含这批大型依赖文件。

## 新下载用户

使用重新生成的完整视频离线 ZIP；其中已经包含依赖，不需要额外放置补充包。不要仅凭同名文件判断版本，应核对随包 SHA-256。

## 维护者打包与验收

`tools/build_breeze_offline.py --wheelhouse <目录> --output Olivia-breeze-runtime-offline.zip` 根据当前视频清单校验并生成补充包。

添加 `--full-source <旧完整视频ZIP>` 可生成新的完整包。构建过程读取并校验旧包的清单文件，不修改旧包；输出路径必须不存在。依赖目录必须预先备齐当前 Windows CPython 3.12 锁定的 wheel。

验收必须在空白依赖环境里安装真实 wheel，并禁止网络连接。哈希检查、单元测试和已有开发环境里的成功结果不能替代这项验证。Breeze 的实际启动检查还要求支持的 NVIDIA GPU；安装通过不等于完整视频生成质量已验收。
