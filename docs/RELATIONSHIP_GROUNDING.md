# 初识关系与记忆提取修复

单方面的「想你」只证明来信人的表达，不证明林离已经同样思念对方。用户问起一段过去，也不证明那段共同经历已经发生。已有关系状态继续生效，不因本次窗口缺少旧信就重置。

人格装配将这条边界保留在必需上下文中；角色未知的身份延续不靠模型补写。资料出处仍保存在人格资产中，但出处编号不作为角色知识发送给模型。记忆提取保留说话者、疑问、否定、具体偏好和条件，不把旧摘要推断当作新事实；使用原有 Mem0 抽取调用，不新增模型复核轮次。

## 验证范围

- 修复迭代中发现并保留失败结果：互相思念、虚构公告阅读、把等待问句记成等待事实、失忆与身份延续叙事。仅通过本地测试不视为修复完成。
- 最终新用户连续三封正式 HTTP 寄信：回信、记忆投递、生活提交完成；五条最终记忆保留原话，没有扩写成持续往来、依赖或共同等待。重新打开生活数据库一致。
- 两封问句变体：记忆保留为提问，没有转成过去的肯定事实。熟悉关系两封对照没有被重置为陌生关系。
- 七组历史信件在旧提取规则下完成正式 HTTP 导入及新进程重复导入；重复导入不增加模型调用。新提取规则另用一组合成信对验收，具体喜好、周六 15 点钢琴课和等待问句保留；重复导入不重复写入。
- 模型调用使用 OpenCode Go / DeepSeek V4 Flash，Mem0 与 BGE 在隔离测试数据中运行。熟悉关系对照使用显式初始化的合成关系，不等同于真实用户档案迁移。

这些是有限案例的链路证据，不是零幻觉率，也不是所有用户设备的原生界面验收。部分回信措辞仍生硬。修复不自动清空或重写已有错误摘要，用户可在长期记忆中纠正具体记录。

联合更新还包含历史记忆写入等待、主动恢复已耗尽记忆任务以及诊断信息增强。恢复操作不清除累计失败次数；不能据此断言尚未取得底层错误的用户问题已经根治。
