## 用户确认的需求

- [x] 对外模块改名“林离世界”，内部接口与数据库标识保持兼容。
- [x] 统一作息状态与用餐、休息、专注时段供回信和页面读取。
- [x] 按实际接收与最终回信完成时间累计睡眠窗口内的清醒时长。
- [x] 最后一次回信后安静满 30 分钟重新入睡；再来信算再次叫醒。连续通信与重复叫醒的影响不同，重复投递不重复计算。
- [x] 疲劳延续次日并可逐步恢复；不因为用户离线自动恶化。
- [x] 关系变化使用既有账本，不新增独立好感分数；夜间倾诉本身不扣关系。
- [x] 作息按稳定通信或明确且有时区依据的用户习惯渐进适应，保留睡眠时长，不回写旧夜晚。

- 四封 OpenCode Go / DeepSeek V4 Flash 的真实 HTTP 信件已完成：凌晨闲聊、5 分钟后晚安、超过半小时后的倾诉、次日近况。正式回信与生活提取均完成，数据库重开后快照一致。
