# P03 原版 Olivia 客户端集成审计

## 1. 结论与产品边界

原版 Olivia 客户端是本项目唯一面向用户的产品外壳。

```text
原版 Olivia 客户端
  -> 原版信箱、信件详情、设置、弹窗和播放器
  -> 本机 toyApiUrl / toyWsUrl
  -> Persona / Mem0 / PrivateWorld / 媒体后端
```

当前阶段禁止新增或发布：

- 独立浏览器 Control Center；
- 第二套桌面客户端；
- 单独的长期管理窗口；
- 要求普通用户使用的 CLI、JSON 或环境变量；
- 绕开原版客户端的产品验收路径。

仓库中已经存在的 Service、schema、认证和测试可以作为内部实现复用。独立页面和启动入口暂停扩展，不能因为代码已经存在就改变产品路线。

## 2. 当前已经证实的原版客户端事实

### 2.1 支持版本与安装边界

当前安装清单只支持：

```text
Steam App ID: 4532590
Client version: 0.0.9.615
feapp.dat SHA-256:
53babcf288c7679a57eb4a2647397d951ec450d5fdaea634498286b2ebb8136e
Patch mode: isolated-copy
```

安装器先验证版本和完整哈希，再复制原版运行时到隔离目录。源 Steam 安装不被直接修改；补丁失败时删除失败副本，不污染原版。

### 2.2 已知前端主包

当前受支持版本的补丁目标是：

```text
assets/main-917d29fc.js
```

公开仓库不包含原版 `feapp.dat`、JavaScript 主包、官方媒体或其他原版资源。

### 2.3 已知本地服务接入点

当前补丁已证实存在一个 `getClientConfig` 响应处理位置，可在该位置把：

```text
toyApiUrl
toyWsUrl
```

替换为 `127.0.0.1` 本地服务地址。

这意味着后续功能应继续复用原版客户端现有的数据请求和 WebSocket 通道，不新增第二套面向用户的服务器或 UI 通道。

### 2.4 已知信箱入口

受支持版本登录后的已知导航片段包含：

```text
Home
Collection
```

当前 lite 补丁将默认入口从 `Home` 切到原版信箱 `Collection`。因此信箱、信件详情、原版播放器和原版导航是后续集成的首选承载面。

### 2.5 已有安全补丁纪律

现有补丁已经具备：

- 原文件备份；
- ZIP 路径穿越防护；
- 临时目录内修改；
- 原子替换；
- 锚点唯一性检查；
- 修改后验证；
- 任一步失败时恢复原文件；
- 不兼容版本明确停止。

所有新的客户端补丁必须复用同样的安全边界，不能使用模糊全局替换。

## 3. 当前尚未证实的内容

仅凭公开仓库和现有三个补丁锚点，不能诚实确认：

- 原版完整路由表；
- 个人页或设置页的准确路由名；
- 可复用的设置项、弹窗、列表和确认组件；
- 信件详情页面的内部组件边界；
- `reply_video_url` 与原版播放器的准确绑定位置；
- 文字终态、媒体状态和错误提示的渲染逻辑；
- 原版 CSS token、布局组件和交互规范；
- 哪些 minified 标识符在版本更新后仍然稳定；
- MiniMax 校准入口可安全挂载到哪个现有页面。

在这些事实完成审计前，不允许继续编写新的用户页面或猜测路由名。

## 4. 只读审计工具

新增：

```text
tools/audit_original_client.py
```

该工具只读取本机原版 `feapp.dat`，不会：

- 解压到磁盘；
- 修改或重打包原版文件；
- 访问网络；
- 输出 JavaScript 源码；
- 输出绝对路径；
- 输出任意原版文案；
- 输出凭据或用户数据。

它只生成以下脱敏证据：

- archive 和主包 SHA-256；
- 客户端版本目录提示；
- ZIP 成员数量和扩展名计数；
- 当前补丁锚点出现次数；
- 已发现的路由引用名；
- `/toy/...` 本地 API 路径；
- 已知 wire 字段出现次数；
- 固定界面关键词计数；
- 当前文件属于原版可补丁、已补丁或需要人工复核。

本机执行示例：

```powershell
python tools/audit_original_client.py `
  "<Steam安装目录>\0.0.9.615\resources\feapp.dat" `
  --expected-sha256 53babcf288c7679a57eb4a2647397d951ec450d5fdaea634498286b2ebb8136e `
  --output original-client-audit.json
```

只需要提供生成的 `original-client-audit.json`。不要上传或提交原版 `feapp.dat`、解包后的资源或完整 JavaScript。

## 5. 审计后才能确定的信息架构

以下只是产品位置原则，不是已经确认的路由实现。

### 5.1 信件详情

优先承载与当前信件直接相关的信息：

- canonical text；
- 文字终态；
- 独立媒体状态；
- 最终说话视频或音乐视频；
- 与该封信直接关联的 PrivateWorld 候选确认。

### 5.2 原版设置或个人入口

审计确认存在合适入口后，承载：

- Mem0 记忆查看、搜索、纠正和删除；
- 私人称呼、住所权限和 Local Continuation；
- 本地模型、记忆和媒体能力状态；
- 必要的本机路径选择和凭据配置。

### 5.3 隐藏的开发校准入口

MiniMax 固定样本生成和盲听评分只在开发或高级模式出现，不进入普通书信体验，也不创建外部浏览器页面。

## 6. 已合入 standalone Control Center 代码的处理

在原版客户端集成完成前：

```text
control_center/ 后端 Service、schema、认证、API 测试
  -> 冻结并评估是否作为内部实现复用

control_center/ 独立 HTML/CSS/JS 页面、浏览器启动 URL
  -> 不进入发布路径

独立 Control Center / Diagnostics 快捷方式
  -> 不创建
```

后续删除或保留必须由原版客户端接线结果决定，不能为了“清理”先破坏已经完成的业务 Service。

## 7. 后续 PR 顺序

### CLIENT-UI-01A：只读审计工具与证据边界

本文件及审计工具。不得修改原版 UI 或运行时行为。

### CLIENT-UI-01B：受支持版本的脱敏审计结果

基于本机原版 `feapp.dat`：

- 核验现有锚点；
- 记录路由引用和 wire 字段；
- 形成需要人工查看的页面清单；

- 原版组件复用方式；
- 每个补丁锚点的唯一性和回滚条件。

先完成：

```text
文字终态
+ media status
+ 原版播放器

```

### CLIENT-UI-04：记忆与私人世界设置

只在原版设置或个人入口内实现最小管理能力。

### CLIENT-UI-05：隐藏 MiniMax 校准入口

完成本机音频实验后再决定是否保留。

### CLIENT-UI-06：冻结或移除 standalone 发布入口

确认原版客户端已经覆盖必要能力后，再删除或降级重复 UI。

### CLIENT-UI-07：原版客户端真实验收

所有产品 PASS 必须从原版客户端发起和观察。
