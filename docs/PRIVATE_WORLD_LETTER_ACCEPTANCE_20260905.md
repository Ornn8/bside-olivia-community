## 第二轮：事实核对、回信引用和普通接话分开

### 发现与改动

当前新信件的 Mem0 写入只提供用户原信，未把生成回信一并送去提取用户事实。新增带有虚构次数和动机的回信反例保护这条边界，未更改记忆写入算法，也没有清除任何旧记忆。

短期窗口此前混合提供用户陈述与她的整封回信。模型不仅会沿用旧判断，还会把后来发生的多次提问倒用作早先判断的依据。单纯删风格、改调侃规则、追加计数禁令或改成原生多轮消息均不能稳定纠正；这些实验没有进入人格资产或生产调用。

现按查询目的渐进提供原始证据，仍在原有 2800 字符预算内：

- 核对过去事实：只提供用户原信，不用旧回信中的猜测证明用户行为。明确区分人物、行动、时间与否定范围，未知次数和动机不补写。
- 追问她的某句话：提供匹配的那一次完整往来；“刚才/上一封”取最近一封，带具体引用则按双方正文检索。不要把后来无关的往来作为早先判断的证据，也不把她说过的判断等同于事实。
- 普通接话：保留最近两封双方正文和最多两封较早相关用户原信。原始信箱记录始终不改写、不删除。

这是本地文本路由与上下文选择，不新增分类模型、语义复核、重写调用或存储层；主回信思考保持开启。路由目前覆盖常见中文及部分英文表达，不是完备的自然语言意图分类器。

最终 `world-http-20260905-211822` 从空记录发八封：正式回信与生活写入 8/8 完成，记忆终态 8、待处理 0，重复发送未新增，重开快照一致。核对和玩笑不增加紧张值；明确命令使紧张值 0→3，道歉撤回后 3→1，信任和舒适各增加 1。酸口、微辣、不吃香菜、冰饮胃痛和温水均能从真实记忆接口读取并在下一封召回。对应 CI 为 2339 passed、2 skipped、1 deselected。

### PR #379：保留命题范围，不把检索顺序当通信顺序

否定/假设说明原先只在事实核对路由中出现，用户直接陈述假设时仍会越界推断。历史摘录的 `time` 实际为回信完成时间，不能证明来信相邻。修复补足陈述和提问共同使用的三态依据规则：个人经历分别为已知肯定、已知否定或未知；“做过”与“没做过”都需原信依据。历史摘录仅在存在时附上时序说明，不按窗口位置称“上一封/刚才”。

中间版本 `world-http-20260905-214410` 的前两封已不再断言用户没去过青岛，但补出了“台上台下你都待过”；这也是无依据扩张，不能算语义通过。后续固定输入回放把三态规则同时应用于肯定和否定，未再补出个人上台经历。回放不能替代最终接口验收。

渐进披露保持原有约束：历史总预算 2800 字符，不提供完整聊天记录；事实核对只取用户原信，明确追问旧回信才提供匹配往来，普通接话保留最近两封及有限相关旧原信。人格 anchor 选择、模式风格、30k 总预算均不扩大。新增回归覆盖无历史的陈述句、稀疏历史不能证明相邻、真实发送入口携带规则；先前的完整否定原文、明确练习次数、旧回信污染隔离和人格选择回归继续保留。

本轮真实接口验收还覆盖独自去过/虚构同行、音乐会只当听众而未上台、未说明是否去过另一城市、较早原信归属、口味与次数召回、玩笑、命令拒绝及道歉修复。最终结果和未解决项以 [PR #379 验收记录](https://github.com/Ornn8/bside-olivia-community/pull/379) 为准，不能从本节的规则和测试设计推断全部语义通过。本轮同样未验证安装版、自然日推进或视频生成。
